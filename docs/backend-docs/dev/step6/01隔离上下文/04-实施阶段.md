## 10. 风险点（详见 [`06-风险与回滚`](06-风险与回滚.md)）

| 风险 | 等级 | 触发条件 | 处置 |
| :-- | :--: | :-- | :-- |
| 启动报错找不到 module | 高 | import 改漏了 | 用脚本批量改；每阶段先做静态扫描 |
| 路由路径冲突 | 中 | 同一个 prefix 多次 include | 启动时检测 `app.routes` 是否有重复 |
| ORM 关系断裂 | 中 | 模型跨 context 引用 | 检查所有外键 |
| 采集任务不启动 | 高 | collect 找不到 data gateway | 启动时断言 `data` 已 setup |
| 前端报错 | 中 | 路径或 schema 变了 | **不**改路径，**不**改 schema |
| 性能下降 | 低 | import 链变长 | Python 启动期慢 1~2 秒可接受 |
