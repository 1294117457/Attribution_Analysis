## 关键决策速查

| 决策点 | 选择 | 理由 |
|---|---|---|
| 实时机制 | 15s 轮询 | 零后端改动；足够看盘 |
| 看板预设 | localStorage | 零后端压力；如需云端再扩 |
| 概念大盘路由 | 独立 `/home/concepts` | 与 SectorBoard 并列；概念数据已可用 |
| Dashboard 处理 | 重写（路由不变） | 现状版功能太简单 |
| 视图切换性能 | 共享 `items` 引用 + v-if | 切换 < 50ms |
| 热力图 | ECharts Treemap | 项目已有依赖；自动布局 |
| 多股对比 | 通用组件嵌入 3 页 | 复用 `/stocks/{s}/analysis` |
| 同业对比 | 大屏内嵌 | 不抽通用组件；本期只用一次 |
