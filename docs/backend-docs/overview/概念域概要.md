# 概念域 · 概要（`concept` context）

> 面向"需要快速理解同花顺概念采集、概念大盘、概念实时行情和降级的开发者"。
> DDD 位置：`backend/src/contexts/concept/`（`interface` → `application` → `domain` ← `infrastructure`）。
> 跨 context 依赖：通过 `collect.application.service.collect_manage_service.run_one` 触发采集；通过 `market.application.service` 调股票基础信息；通过 `shared.infrastructure.adapter.data.DataGateway` 走实时接口（`concept_minute`）。

页面：`frontend/src/views/concept-board/ConceptBoard.vue`（概念大盘：涨幅榜 / 跌幅榜 / 卡片网格 / 成分股抽屉）
应用服务：`backend/src/contexts/concept/application/service/{concept_service, concept_board_service, concept_realtime}.py`
领域服务：`backend/src/contexts/concept/domain/service/{concept_brief_service, concept_collection_policy}.py`
接口：`/api/v1/concepts/*`

最后更新：2026-10-17（step7 统一 DDD 重构后）

---

## 1. 现状一句话

`concept` context 负责 A 股"同花顺概念"的查询域：概念清单（`fundamental_concept` 390 个）+ 成分股（`fundamental_concept_member` 70K+）+ 概念指数日 K（`fundamental_concept_index` 542K+，**也是实时行情的降级数据源**）+ 概念行情快照（`fundamental_concept_snapshot` 390 行）。**5 个批量任务**走 adata（`concept` / `concept_membership` / `concept_index_th` / `concept_reason` / `concept_snapshot`），1 个**实时接口** `concept_minute`（`ConceptMinutePort` → `AdataConceptMinuteAdapter`）。实时行情失败时由 `ConceptRealtimeReader` 回落 `fundamental_concept_index` 最近一天收盘（`stale=true`，不缓存）。鉴权当前阶段保持公开。

│       └── concept_realtime.py          # ConceptRealtimeReader：实时行情 + 降级（回落 fundamental_concept_index 最近收盘）
├── infrastructure/
│   ├── di/                      # di_concept.py

    └── dto/                     # 请求 DTO / 响应 VO

跨 context：
- **采集复用**：5 个概念任务由 `collect.application.service` 注册，运行时经 `DataGateway` 调 adata Adapter（`shared.infrastructure.adapter.data.adata.*`）；
- **实时接口**：`ConceptMinutePort` 声明 `cache = CachePolicy(ttl_trading=15s, ...)`，`CacheDecorator` 缓存 15 秒，`market_session.ttl_for` 决定 TTL；
- **降级**：`ConceptRealtimeReader`（应用层）失败时回落 `fundamental_concept_index` 最近一天收盘，标 `stale=true`，不缓存；
- **股票存在性**：`concept_service` 反查股票所属概念时调 `market.application.service.stock_info_service` 校验；
- **路由聚合**：`concept.py` 的路由被 `shared.interface.router_compat.api_router` 挂到 `/api/v1`。

## 3. 数据模型

| 表 | 关键字段 | 行数 | 写入方 |
|---|---|---|---|
| `fundamental_concept` | `index_code`（885xxx，UK）· `name` · `concept_type`（`地区` / `行业` / `概念` / `风格` 等）· `source` | 390 | `concept` 任务 |
| `fundamental_concept_member` | `(symbol, index_code)` UK · `reason`（入选理由，adata 同花顺） | 70,470 | `concept_membership` + `concept_reason` 任务 |
| `fundamental_concept_index` | `(index_code, trade_date)` UK · OHLCV + change_pct | 542,648 | `concept_index_th` 任务（也是实时降级数据源） |
| `fundamental_concept_snapshot` | `index_code` · `trade_date` · `price` / `change` / `change_pct` · `turnover_rate` / `volume` · `source` | 390 | `concept_snapshot` 任务 |

> `concept_reason` 任务的产物写进 `fundamental_concept_member.reason`（不新建表），按 `only_missing=true` 默认只回填空值。

## 5. 实时接口（`concept_minute`）

| 项 | 值 |
|---|---|
| 数据源 | 同花顺 adata `get_market_concept_min_ths`（`AdataConceptMinuteAdapter`） |
| Port | `ConceptMinutePort`（`collect.application.port.data.concept.ConceptMinutePort`） |
| 缓存 | `CacheDecorator` 15 秒（TTL 由 `market_session.ttl_for` 决定） |
| 限流 | `adata:ths` 限流组并发 = 5 + 间隔 0.5s |
| 超时 | 单次 10 秒 → `SourceUnavailable` → 502 |
| 响应 | `ConceptMinuteBO`：当日分时 `points` + 头部 `pre_close / price / change / change_pct / trade_time` |
| 降级 | `ConceptRealtimeReader` 失败时回落 `fundamental_concept_index` 最近一天收盘，标 `stale=true`，**不缓存** |
| Redis | `ds:cache:{port}:{hash}` / `ds:lock:{port}:{hash}` / `ds:stats:{port}:{tool}:{yyyymmdd}` |

### 端点

- `POST /api/v1/collect/realtime/concept_minute/query`（试查，不降级）
- `GET /api/v1/collect/realtime/concept_minute/stats?days=1`（按天统计：calls / hits / misses / errors / hit_rate / avg_latency_ms / last_error）

## 6. 采集任务

| task_type | 单元 | 数据源 | 写入表 | 默认参数 |
|---|---|---|---|---|
| `concept` | 全量一次 | adata `all_concept_code_ths` | `fundamental_concept` | `{}` |
| `concept_membership` | 概念（`index_code`） | adata `concept_constituent_ths` | `fundamental_concept_member` | `{}` |
| `concept_index_th` | 概念 | adata `get_market_concept_ths` | `fundamental_concept_index` | `{}`（增量）/ `{"full": true}`（全量） |
| `concept_reason` | 股票 | adata `get_concept_ths` | `fundamental_concept_member.reason` | `{"only_missing": true}` |
| `concept_snapshot` | 概念 | adata `get_market_concept_current_ths` | `fundamental_concept_snapshot` | `{}` |

依赖顺序：`concept` → `concept_membership` → `concept_reason`；`concept` → `concept_index_th` / `concept_snapshot`。可在同一采集方案内按 `sort_order` 串行执行。

### 缩量保护（`concept_collection_policy`）

- 清单缩量：返回清单 < 库中活跃 × 80% 时不删除旧的（避免误判）；
- 成分股骤降：成分股数 ≤ `max(20, 旧数 × 50%)` 时保留旧关系。
