# 操作池 - 异步任务设计

> 本文档定义"操作池"模块的异步任务执行方案：任务派发、进度更新、并发控制。
>
> **目标**：支持大池（1000+ 成员）批量操作时不阻塞 HTTP 请求，用户可通过轮询 / SSE 追踪进度。

---

## 1. 背景与约束

### 1.1 问题

| 场景 | 问题 |
|------|------|
| 采集 1000 只股票的 K 线 | 单次 HTTP 5 分钟+，超时 |
| 采集失败处理 | 需要知道哪只股票成功/失败 |
| 任务中断 | 用户关闭页面后任务是否继续 |
| 进度显示 | 实时进度需要推送到前端 |

### 1.2 约束

| 约束 | 说明 |
|------|------|
| 不引入 RabbitMQ / Redis | 保持架构简单，使用 asyncio 原生方案 |
| 不引入 Celery | 同上 |
| 不阻塞 HTTP | 任务派发后立即返回 |
| 进度持久化 | 任务中断重启后可恢复 |

---

## 2. 方案选择

### 2.1 可选方案对比

| 方案 | 优点 | 缺点 | 推荐 |
|------|------|------|------|
| **asyncio.create_task** | 零依赖，原生集成 | 单进程，进程崩则任务丢 | ✅ v1 |
| Python `threading.Thread` | 可后台运行 | GIL 限制，调试困难 | ❌ |
| Celery + Redis | 任务队列成熟 | 引入外部依赖 | P2 |
| FastAPI BackgroundTasks | 原生支持 | 不支持分布式 | P1 过渡 |
| asyncio + uvloop | 高性能 | 仅 Linux | P2 |

### 2.2 v1 决策：**asyncio.create_task + 全局任务注册表**

**理由**：
1. 项目已有 `asyncio` 基础设施（SQLAlchemy AsyncSession）
2. 任务数有限（用户主动发起），不需要队列
3. 可通过注册表实现任务取消 / 进度追踪

### 3.1 核心组件

## 4. 任务注册表

```python
# infrastructure/tasks/registry.py

from __future__ import annotations

import asyncio
import logging
from typing import Optional
from weakref import WeakValueDictionary

logger = logging.getLogger(__name__)


class TaskRegistry:
    """全局任务注册表

    使用 WeakValueDictionary，当 asyncio.Task 完成时自动清理引用。
    """

    def __init__(self):
        self._tasks: dict[int, asyncio.Task] = {}

    def register(self, op_id: int, task: asyncio.Task) -> None:
        """注册任务"""
        self._tasks[op_id] = task
        logger.info("任务注册: op_id=%d", op_id)

    def unregister(self, op_id: int) -> None:
        """注销任务"""
        self._tasks.pop(op_id, None)
        logger.info("任务注销: op_id=%d", op_id)

    def get(self, op_id: int) -> Optional[asyncio.Task]:
        """获取任务"""
        return self._tasks.get(op_id)

    def cancel(self, op_id: int) -> bool:
        """取消任务"""
        task = self._tasks.get(op_id)
        if task and not task.done():
            task.cancel()
            logger.info("任务已取消: op_id=%d", op_id)
            return True
        return False

    def is_running(self, op_id: int) -> bool:
        """任务是否运行中"""
        task = self._tasks.get(op_id)
        return task is not None and not task.done()

    def list_running(self) -> list[int]:
        """列出所有运行中的任务"""
        return [op_id for op_id, task in self._tasks.items() if not task.done()]

    @property
    def count(self) -> int:
        return len(self._tasks)


# 全局单例
_global_registry: Optional[TaskRegistry] = None


def get_task_registry() -> TaskRegistry:
    global _global_registry
    if _global_registry is None:
        _global_registry = TaskRegistry()
    return _global_registry
```

## 5. 任务派发器

```python
# infrastructure/tasks/operation_dispatcher.py

from __future__ import annotations

import asyncio
import logging
from datetime import datetime
from typing import Optional

from sqlalchemy.ext.asyncio import AsyncSession

from domain.stock_pool.repository import PoolOperationRepository
from domain.stock_info.repository import StockInfoRepository
from application.kline_service import KlineAppService
from infrastructure.repositories.pool_operation_repository import PoolOperationRepoImpl
from infrastructure.repositories.stock_repository import StockRepoImpl
from infrastructure.tasks.registry import get_task_registry

logger = logging.getLogger(__name__)


class OperationDispatcher:
    """池操作任务派发器"""

    def __init__(self, session: AsyncSession):
        self._session = session
        self._op_repo: PoolOperationRepository = PoolOperationRepoImpl(session)
        self._stock_repo: StockInfoRepository = StockRepoImpl(session)
        self._registry = get_task_registry()

    async def dispatch_kline_collect(
        self,
        op_id: int,
        pool_id: int,
        symbols: list[str],
        days: int = 365,
        source: Optional[str] = None,
    ) -> None:
        """派发 K 线采集任务（立即返回）"""

        async def _run() -> None:
            """实际执行任务的异步函数"""
            logger.info("任务开始: op_id=%d, pool_id=%d, symbols=%d", op_id, pool_id, len(symbols))

            try:
                # 更新状态为 running
                await self._op_repo.update_status(
                    op_id,
                    status="running",
                    started_at=datetime.now(),
                )

                # 创建应用服务（每个任务用独立 session）
                from infrastructure.database.connection import async_session_maker
                async with async_session_maker() as task_session:
                    kline_service = KlineAppService(session=task_session)

                    done = 0
                    failed = 0
                    saved_total = 0
                    details = []

                    for symbol in symbols:
                        # 检查是否被取消
                        if not self._registry.is_running(op_id):
                            logger.info("任务已取消，停止执行: op_id=%d", op_id)
                            break

                        try:
                            # 复用现有 KlineAppService.collect
                            result = await kline_service.collect(
                                symbol=symbol,
                                days=days,
                            )
                            saved_total += result.get("saved_count", 0)
                            details.append({
                                "symbol": symbol,
                                "status": "success",
                                "count": result.get("saved_count", 0),
                            })
                            logger.debug("采集成功: symbol=%s, count=%d",
                                         symbol, result.get("saved_count", 0))
                        except Exception as e:
                            failed += 1
                            details.append({
                                "symbol": symbol,
                                "status": "failed",
                                "message": str(e),
                            })
                            logger.warning("采集失败: symbol=%s, error=%s", symbol, e)

                        done += 1
                        # 更新进度（每只完成后立即写 DB）
                        await self._op_repo.update_progress(
                            op_id, done=done, total=len(symbols), failed=failed
                        )

                    # 计算最终状态
                    status = "success" if failed == 0 else "partial"
                    result_summary = {
                        "total": len(symbols),
                        "saved": saved_total,
                        "skipped": 0,
                        "failed": failed,
                        "details": details,
                    }

                    # 更新结果
                    await self._op_repo.update_status(
                        op_id,
                        status=status,
                        finished_at=datetime.now(),
                    )
                    await self._op_repo.update_result(op_id, result_summary)

                    logger.info(
                        "任务完成: op_id=%d, status=%s, saved=%d, failed=%d",
                        op_id, status, saved_total, failed
                    )

            except asyncio.CancelledError:
                logger.info("任务被取消: op_id=%d", op_id)
                await self._op_repo.update_status(
                    op_id,
                    status="cancelled",
                    finished_at=datetime.now(),
                )
                raise
            except Exception as e:
                logger.exception("任务异常: op_id=%d", op_id)
                await self._op_repo.update_status(
                    op_id,
                    status="failed",
                    error_message=str(e),
                    finished_at=datetime.now(),
                )
            finally:
                # 注销任务
                self._registry.unregister(op_id)

        # 创建 asyncio.Task 并注册
        task = asyncio.create_task(_run())
        self._registry.register(op_id, task)

    async def cancel_operation(self, op_id: int) -> bool:
        """取消操作"""
        return self._registry.cancel(op_id)
```

### 6.2 SSE 接口（推荐 P1）

```python
# route/api/v1/operation_stream.py（新增路由）

from fastapi import APIRouter, Path
from fastapi.responses import StreamingResponse
import asyncio
import json

router = APIRouter(tags=["Operation Stream"])


@router.get(
    "/api/v1/operations/{op_id}/stream",
    summary="操作进度 SSE 流",
    response_class=StreamingResponse,
)
async def operation_stream(op_id: int = Path(...)):
    """SSE 流推送操作进度"""

    async def event_generator():
        registry = get_task_registry()
        last_progress = None

        while True:
            # 检查任务是否还在运行
            if not registry.is_running(op_id):
                # 发送最终状态
                yield f"event: finished\ndata: {json.dumps({'status': 'done'})}\n\n"
                break

            # 读取最新进度（从 DB）
            from infrastructure.database.connection import async_session_maker
            async with async_session_maker() as session:
                op_repo = PoolOperationRepoImpl(session)
                op = await op_repo.find_by_id(op_id)
                if op and op["progress"] != last_progress:
                    last_progress = op["progress"]
                    yield f"event: progress\ndata: {json.dumps(op['progress'])}\n\n"

            await asyncio.sleep(1)  # 每秒推送

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "Connection": "keep-alive",
        },
    )
```

## 7. 任务中断与恢复

### 7.1 中断处理

| 场景 | 处理 |
|------|------|
| 用户取消 | `registry.cancel(op_id)` → `task.cancel()` |
| 进程重启 | `pool_operations` 表中 `status=running` 的任务需要处理 |
| 进程崩溃 | 任务丢失，用户需手动重试 |

### 7.2 重启恢复（v2）

```python
async def recover_pending_operations():
    """应用启动时恢复未完成的任务"""
    from infrastructure.database.connection import async_session_maker

    async with async_session_maker() as session:
        op_repo = PoolOperationRepoImpl(session)
        # 查找状态为 running 但 started_at 超过 1 小时的记录
        from sqlalchemy import select
        from infrastructure.database.models.pool import PoolOperationDB
        from datetime import timedelta

        cutoff = datetime.now() - timedelta(hours=1)
        result = await session.execute(
            select(PoolOperationDB).where(
                PoolOperationDB.status == "running",
                PoolOperationDB.started_at < cutoff,
            )
        )
        stale_ops = result.scalars().all()

        for op in stale_ops:
            # 标记为 failed
            await op_repo.update_status(
                op.id,
                status="failed",
                error_message="任务超时未完成",
                finished_at=datetime.now(),
            )
            logger.warning("恢复超时任务: op_id=%d", op.id)
```

## 8. 并发控制

### 8.1 全局并发限制

```python
# infrastructure/tasks/registry.py（补充）

class TaskRegistry:
    MAX_CONCURRENT = 3  # 最多同时运行 3 个任务

    def register(self, op_id: int, task: asyncio.Task) -> bool:
        """注册任务，如果超过并发限制则拒绝"""
        running_count = len(self.list_running())
        if running_count >= self.MAX_CONCURRENT:
            logger.warning("并发任务数已达上限: %d", self.MAX_CONCURRENT)
            return False
        self._tasks[op_id] = task
        return True
```

## 10. 错误处理策略

| 错误类型 | 处理 |
|---------|------|
| 网络错误（Tushare / AkShare） | 标记 `failed=1`，继续下一只 |
| 单只股票数据不存在 | 标记 `skipped`，继续下一只 |
| 单只股票字段异常 | 标记 `failed`，记录错误信息，继续下一只 |
| 任务被取消 | 标记 `cancelled`，停止循环 |
| 任务超时（1h） | 标记 `failed`（重启恢复时处理） |
| 进程崩溃 | 任务丢失，用户手动重试（P0）/ 自动恢复（P2） |

## 13. P0 vs P1 vs P2

| 阶段 | 内容 | 说明 |
|------|------|------|
| **P0** | asyncio.create_task + 轮询 | 基础可用 |
| **P1** | SSE 推送 + 取消操作 | 改善体验 |
| **P2** | 任务持久化 + 重启恢复 | 可靠性增强 |
| **P2** | Celery 迁移 | 分布式支持 |
