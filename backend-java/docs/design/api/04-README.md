## 3. 一页纸速览

### 3.1 接口风格

- **纯 REST + HTTP 语义方法**
- 路径：模块 / 资源 / `{id}` / `[?query]`
- 查询用 GET，写用 POST/PUT/PATCH/DELETE

### 3.2 路径规范

- **资源名** = 复数或抽象名词（`info` / `members` / `tasks`）
- **路径参数** = 资源主键（单一或复合）
- **query 参数** = 过滤 / 分页 / 排序
- **body 参数** = 资源内容 / 批量明细
- **优先扁平**，但**允许多层 id**（复合主键、进度子视图、取消子动作等场景保留多层）

### 3.3 分页响应

```jsonc
{
  "total": 153,
  "page": 1,
  "pageSize": 20,
  "dataList": [ ... ]    // 永远不返回 null
}
```

### 3.4 响应封装

```jsonc
{
  "code": 0,             // 0 = 成功
  "data": { ... },
  "msg": "ok"
}
```
