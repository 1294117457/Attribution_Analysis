## 1. TaskOutcome（采集任务一次执行的结果）

现在的规则（`base.py`）：

```python
def _decide_status(summary: TaskSummary) -> str:
    """兼容既有"部分失败也算成功"的语义"""
    if summary.success == 0 and summary.fail > 0:
        return "failed"
    return "success"
```

改造后：

```python
# domain/entitys/collect_task/vo.py
@dataclass(frozen=True)
class TaskOutcome(ValueObject):
    """一次采集任务执行的统计结果"""
    success: int
    fail: int
    skip: int = 0

    @property
    def status(self) -> str:
        """最终状态：零成功且有失败 → failed；其余（含部分失败）→ success"""
        return "failed" if self.success == 0 and self.fail > 0 else "success"

    @property
    def all_failed(self) -> bool:
        return self.success == 0 and self.fail > 0
```

- `cancelled` 不在这里判定：取消是执行过程中的外部事件，由 runner 直接写 `cancelled`。
- "部分失败也算 success"是既有语义（前端历史列表依赖），保持不变。

## 2. PlanStopPolicy（方案失败即停）

现在的规则（`collect_manage_service.py::run_plan`）：

```python
# ⚠️ 不能只看 status —— _decide_status 里"部分失败也算 success"，
#   所以额外拦"零成功但有失败"的极端情况。
if stop_on_fail and (
    status in ("failed", "cancelled") or (ok == 0 and fail > 0)
):
    break
```

改造后：

```python
# domain/entitys/collect_plan/vo.py（与 Schedule 同文件）
@dataclass(frozen=True)
class PlanStopPolicy(ValueObject):
    """方案执行的编排策略：某一项结束后是否停止后续项"""
    stop_on_fail: bool = True

    def should_stop(self, status: str, outcome: TaskOutcome) -> bool:
        if not self.stop_on_fail:
            return False
        return status in ("failed", "cancelled") or outcome.all_failed
```

- `status` 单独传入：取消时 `outcome` 只是累计值，状态由 runner 决定。
- `run_plan` 改为：

```python
policy = PlanStopPolicy(stop_on_fail=plan.stop_on_fail)
...
record = await self._tasks.get(sub.task_id)          # 02 的 CollectTaskStorePort
outcome = TaskOutcome(record.success_count, record.fail_count, record.skip_count)
if policy.should_stop(record.status, outcome):
    break
```

## 4. 验收

- `TaskOutcome` / `PlanStopPolicy` 单测：成功 0 失败 1 → failed；成功 1 失败 5 → success；`stop_on_fail=False` 恒不停；`cancelled` 必停；零成功有失败但 status=success（理论上不会出现，规则仍兜底）→ 停。
- `domain/entitys/collect_task/`、`collect_plan/` 不 import 任何第三方库。
- `base.py` / `collect_manage_service.py` 中不再出现 `success == 0 and fail > 0` 这类内联判断。
