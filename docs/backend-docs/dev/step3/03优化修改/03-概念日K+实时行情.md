# 03 · 概念看板同时显示日 K + 实时行情

## 1. 需求

**用户原话**："概念看板，可以说基于概念日 k 显示各个概念的 kline 吗，同时又可以显示实时行情"

**解读**：
- 进入某个概念的成分股 Tab 时，能在该概念头部展示该**概念指数**的 K 线图
- K 线是历史日 K（基于 `concept_index_ths` 同花顺数据）
- 同时显示**当日实时行情**（最新价、涨跌幅、买卖盘等）

- 数据是否齐全——通过 SQL `SELECT COUNT(DISTINCT index_code), MIN(trade_date), MAX(trade_date) FROM concept_index_ths` 验证（**待执行**）

**Repository 接口**（伪代码）：

```python
async def get_kline(
    self,
    index_code: str,
    start_date: date | None = None,
    end_date: date | None = None,
    limit: int = 250,
) -> list[KlineBar]:
    """返回概念指数的日 K 线，按日期升序

    数据源：concept_index_ths
    返回 dict 列表，路由层组装 VO
    """
```

**SQL**：

```sql
SELECT trade_date, open, high, low, close, volume, amount, change_pct
FROM concept_index_ths
WHERE index_code = :code
  AND (:start IS NULL OR trade_date >= :start)
  AND (:end IS NULL OR trade_date <= :end)
ORDER BY trade_date DESC
LIMIT :limit
```

> 注意：SQL 出来后要反转为升序再返回（前端 K 线库通常要求升序）

**Service 方法**（伪代码）：

```python
async def get_concept_kline(self, index_code: str, days: int = 250) -> dict:
    """概念指数日 K 线 + 实时快照

    返回：
    {
      "kline": [{date, open, high, low, close, volume, change_pct}, ...],  # 升序
      "realtime": {price, change, pct_change, color, trade_time, captured_at, stale} | None,
      "meta": {index_code, name, stock_count, concept_type, ...}
    }
    """
    # 1. K 线
    bars = await self._repo.get_kline(index_code, limit=days)
    # 2. 实时
    realtime = {}
    if self._realtime and index_code:
        results = await self._realtime.query_many("concept_minute", [{"index_code": index_code}])
        if results:
            entity = await self._repo.get_concept_by_index_code(index_code)
            name = entity.name if entity else ""
            realtime = _to_quote(index_code, name, results[0])
    # 3. meta
    entity = await self._repo.get_concept_by_index_code(index_code)
    meta = {...}
    return {"kline": bars, "realtime": realtime, "meta": meta}
```

**路由**（伪代码）：

```python

async def get_concept_kline(
    index_code: str,

```

> 注意：路径 `{index_code}/kline` 必须放在 `/{name}` 通配符**之前**（参考概念大盘 v2 矫正）

## 4. 测试用例

| 场景 | 期望 |
|------|------|
| 抽屉打开某概念 | 显示 K 线图 + 实时快照 + 成分股列表 |
| 该概念无实时数据（stale） | 显示 K 线图 + `实时数据暂不可用` 提示 + 最近收盘价（来自 `get_latest_closes`） |
| 该概念无历史 K 线（未采集） | 提示"暂无历史 K 线数据"+ 实时快照 |
| 切换不同概念 | K 线图重新加载 |
| K 线 + 实时叠加 | 实时价以虚线 / 红点标注在 K 线图最右侧 |
