0.配置机器
    设置三台机器名称，node1，node2，node3
    基于chrony同步三台机器名称
    关闭swap
    确定三台机器同版本（ubuntu22）
1.配置containerd
    2.3.6版本containerd
    sudo apt-get update
    sudo apt-get install -y containerd.io
    containerd --version
2.配置kubeadm
    需要有虚拟内网，vpc，cnn腾讯官方推荐的内网方式不好（vpc不行，cnn收费）
    用tailsclae组成内网（有可能tailscale）服务挂了受一些影响
    但是本地搭一个，没有意义

2.1tailsclae
    安装    curl -fsSL https://tailscale.com/install.sh | sh
    验证    sudo systemctl enable --now tailscaled
            sudo systemctl status tailscaled        
    然后去官网生成auth key
    配置（打开链接）    sudo tailscale up --hostname=node2 --accept-dns=false --ssh=false

2.2按照kubeadm
    kubelet --version

    假设重新起一个集群
        0.处理好每台机器的版本、conrainerd等
        1.配置tailscale内网，
        2.配置kubeadm-config.yaml+kubelet init
        3.node1init，初始化cni-flannel,所有node配置cni镜像
        4.node加入一个集群
2.3装dashboard
    k8s自己的dashboard
        node、pod、container、service
        资源监控（cpu，内存，网络，磁盘）
        单一日志
    KubeSphere
        业务接口监控，聚合日志，告警通知
        微服务治理、应用商店（装mysql等），rbac，devops
        但是总体占8g，当前不用
