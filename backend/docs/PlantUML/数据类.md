目前想的数据有四类：
1.技术面：K 线 + 成交量 + 技术指标MA/EMA/MACD/KDJ/RSI（从tushare获取）
2.资金/情绪面：换手率、融资余额、股吧情绪、市场整体成交额（从tushare，爬虫，和计算）
3.基本面：ROE净资产收益、PE市盈率、营收增长率、经营现金流（tushare获取）
4.新闻咨询：影响范围：市场 / 行业 / 个股
内容性质：政策 / 财务 / 经营 / 治理 / 风险 / 国际
时间敏感度：快讯 / 定期 / 深度 / 传闻
情绪方向：利好 / 利空 / 中性 / 复杂
来源可信度：官方 / 主流财经 / 机构 / 社区
因果关系：驱动型 / 反映型 / 复盘型
影响持续时间：脉冲 / 趋势 / 噪音
涉及主体：公司自身 / 产业链 / 监管 / 宏观

# 股票数据获取方案（Tushare）

## 一、数据总览

| 维度        | 数据项              | 获取方式         | 状态           |
| :---------- | :------------------ | :--------------- | :------------- |
| 技术面      | K线、成交量         | `daily`          | ✅ 基础积分可用 |
| 技术面      | MA/EMA/MACD/KDJ/RSI | 自己计算         | ⚠️ 无接口       |
| 资金/情绪面 | 换手率、PE          | `daily_basic`    | ✅ 2000积分     |
| 资金/情绪面 | 融资余额            | `margin`         | ✅ 2000积分     |
| 资金/情绪面 | 市场整体成交额      | `daily` 汇总     | ⚠️ 需自己算     |
| 资金/情绪面 | 股吧情绪            | 爬虫             | ❌ 无接口       |
| 基本面      | ROE、营收增长率     | `fina_indicator` | ✅ 2000积分     |
| 基本面      | 经营现金流          | `cashflow`       | ✅ 2000积分     |
| 新闻资讯    | 全市场快讯          | `news`           | ⚠️ 单独开权限   |

## 二、技术面

### 2.1 接口：`daily`

**用途**：获取股票行情数据，包含 K 线和成交量。

| 项目         | 说明                                |
| :----------- | :---------------------------------- |
| **更新频率** | 交易日 15:00-16:00                  |
| **复权**     | 未复权行情，停牌期间不提供数据      |
| **调取限制** | 基础积分每分钟 500 次，每次 6000 条 |

**输入参数**

| 名称         | 类型 | 必选 | 描述                           |
| :----------- | :--- | :--- | :----------------------------- |
| `ts_code`    | str  | N    | 股票代码（支持多个，逗号分隔） |
| `trade_date` | str  | N    | 交易日期（YYYYMMDD）           |
| `start_date` | str  | N    | 开始日期（YYYYMMDD）           |
| `end_date`   | str  | N    | 结束日期（YYYYMMDD）           |

**输出参数**

| 名称         | 类型  | 描述               |
| :----------- | :---- | :----------------- |
| `ts_code`    | str   | 股票代码           |
| `trade_date` | str   | 交易日期           |
| `open`       | float | 开盘价             |
| `high`       | float | 最高价             |
| `low`        | float | 最低价             |
| `close`      | float | 收盘价             |
| `pre_close`  | float | 昨收价【除权价】   |
| `change`     | float | 涨跌额             |
| `pct_chg`    | float | 涨跌幅（%）        |
| `vol`        | float | 成交量（手）       |
| `amount`     | float | 成交额（千元）     |
| `ah_vol`     | float | 盘后成交量（手）   |
| `ah_amount`  | float | 盘后成交额（千元） |

### 2.2 技术指标计算

MA、EMA、MACD、KDJ、RSI **Tushare 无现成接口**，需要自己用 pandas 或 talib 计算。

## 三、资金/情绪面

### 3.1 接口：`daily_basic`

**用途**：获取换手率、PE 等每日基本面指标。

| 项目         | 说明                             |
| :----------- | :------------------------------- |
| **更新频率** | 交易日 15:00-17:00               |
| **积分要求** | 2000 积分起，5000 积分无总量限制 |
| **单次限制** | 最大返回 6000 条                 |

**输入参数**

| 名称         | 类型 | 必选 | 描述               |
| :----------- | :--- | :--- | :----------------- |
| `ts_code`    | str  | Y    | 股票代码（二选一） |
| `trade_date` | str  | N    | 交易日期（二选一） |
| `start_date` | str  | N    | 开始日期           |
| `end_date`   | str  | N    | 结束日期           |

**输出参数（节选）**

| 名称              | 类型  | 描述                              |
| :---------------- | :---- | :-------------------------------- |
| `ts_code`         | str   | 股票代码                          |
| `trade_date`      | str   | 交易日期                          |
| `close`           | float | 当日收盘价                        |
| `turnover_rate`   | float | 换手率（成交量/无限售流通股数）   |
| `turnover_rate_f` | float | 换手率（自由流通股）              |
| `volume_ratio`    | float | 量比                              |
| `pe`              | float | 市盈率（总市值/净利润，亏损为空） |
| `pe_ttm`          | float | 市盈率（TTM，亏损为空）           |
| `pb`              | float | 市净率                            |
| `ps`              | float | 市销率                            |
| `ps_ttm`          | float | 市销率（TTM）                     |
| `dv_ratio`        | float | 股息率（%）                       |
| `dv_ttm`          | float | 股息率（TTM）                     |
| `total_share`     | float | 总股本（万股）                    |
| `float_share`     | float | 流通股本（万股）                  |
| `free_share`      | float | 自由流通股本（万）                |
| `total_mv`        | float | 总市值（万元）                    |
| `circ_mv`         | float | 流通市值（万元）                  |
| `limit_status`    | int   | 收盘涨跌状态                      |

**注意**：PE 归入**基本面**，换手率归入**资金面**，存表时按维度分开。

### 3.2 接口：`margin`

**用途**：获取融资融券每日交易汇总数据。

| 项目         | 说明                                                 |
| :----------- | :--------------------------------------------------- |
| **更新时间** | 交易所每天 8:30 左右更新上一日数据，最晚 9:05 更新完 |
| **特别注意** | 深交所和北交所每周五的数据在下周一上午更新           |
| **单次限制** | 最大返回 4000 行                                     |
| **积分要求** | 2000 积分                                            |

**输入参数**

| 名称          | 类型 | 必选 | 描述                       |
| :------------ | :--- | :--- | :------------------------- |
| `trade_date`  | str  | N    | 交易日期                   |
| `start_date`  | str  | N    | 开始日期                   |
| `end_date`    | str  | N    | 结束日期                   |
| `exchange_id` | str  | N    | 交易所代码（SSE/SZSE/BSE） |

**输出参数**

| 名称          | 类型  | 描述               |
| :------------ | :---- | :----------------- |
| `trade_date`  | str   | 交易日期           |
| `exchange_id` | str   | 交易所代码         |
| `rzye`        | float | 融资余额（元）     |
| `rzmre`       | float | 融资买入额（元）   |
| `rzche`       | float | 融资偿还额（元）   |
| `rqye`        | float | 融券余额（元）     |
| `rqmcl`       | float | 融券卖出量         |
| `rzrqye`      | float | 融资融券余额（元） |
| `rqyl`        | float | 融券余量           |

### 3.3 市场整体成交额

**无专用接口**，从 `daily` 取全市场数据后，按交易日汇总 `amount` 字段。

### 3.4 股吧情绪

**Tushare 无接口**，需要自己爬取东方财富股吧或雪球讨论。

## 六、积分规划

| 阶段                | 可用接口                                              | 说明                    |
| :------------------ | :---------------------------------------------------- | :---------------------- |
| **基础积分（120）** | `daily`                                               | 技术面 K线 + 成交量     |
| **2000 积分**       | `daily_basic`、`margin`、`fina_indicator`、`cashflow` | 资金面 + 基本面核心数据 |
| **单独开通**        | `news`                                                | 新闻资讯                |

**建议顺序**：

1. 先用 `daily` 把技术面跑通
2. 攒到 2000 积分后接入 `daily_basic`、`fina_indicator`
3. 再开通新闻权限
4. 股吧情绪作为补充数据源单独处理

## 七、关键注意事项

| 问题                  | 说明                                                         |
| :-------------------- | :----------------------------------------------------------- |
| **复权**              | `daily` 是未复权行情，算指标前需自己处理                     |
| **财务修正**          | `fina_indicator` 和 `cashflow` 要用 `update_flag=1` 筛选最新数据 |
| **单次限制**          | `fina_indicator` 最多 100 条，只能按单只股票查询             |
| **数据延迟**          | `margin` 是 T+1 更新，深交所/北交所周五数据下周一才更新      |
| **接口相同≠维度相同** | PE 和换手率同在 `daily_basic`，但 PE 归基本面，换手率归资金面 |
