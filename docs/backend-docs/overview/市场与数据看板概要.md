# 市场与数据看板 · 概要（`market` context）

> 面向"需要快速理解股票基本信息、4 数据面查询接口、K 线计算/复权、分钟 K 实时查询和 AI 归因入口的开发者"。
> DDD 位置：`backend/src/contexts/market/`（`interface` → `application` → `domain` ← `infrastructure`）。
> 跨 context 依赖：通过 `collect.application.service.collect_manage_service.run_one` 触发业务侧采集（`/stocks/sync`、`/klines/collect`、池操作）；通过 `shared.infrastructure.adapter.data.DataGateway` 走实时接口（`stock_minute_kline`）。

页面：`frontend/src/views/stock-info/StockInfoList.vue`（股票面板）· `views/data-board/DataBoard.vue`（4 数据面单股看板）· `views/stock-info/ConceptTab.vue`（概念 Tab）
应用服务：`backend/src/contexts/market/application/service/{stock_info_service, data_query_service, panel_compose_service}.py`
领域服务：`backend/src/contexts/market/domain/service/{indicator_calculator, signal_detector, market_session}.py`
接口：`/api/v1/stocks/*`、`/api/v1/stock-panel/*`、`/api/v1/data-board/*`、`/api/v1/klines/*`、`/api/v1/minute-klines/*`

最后更新：2026-10-17（step7 统一 DDD 重构后；底层采集优化 P1–P6 落地；技术指标在请求时实时计算）

## 1. 现状一句话

`market` context 是 A 股个股的"查询域"：以 `fundamental_stock_basic` 为主索引，向上提供股票基本信息 CRUD（`/stocks/*`）、AI 归因统一入口（`/stocks/{symbol}/analysis`）、股票面板（`/stock-panel/*`）、四数据面单股看板（`/data-board/*` 20 端点）、K 线查询与采集入口（`/klines/*`、`/minute-klines/*`）。**指标不入库**：`tech_daily` 只存 OHLCV，18 个技术指标（MA/EMA/MACD/KDJ/RSI/BOLL 等）在请求时由 `IndicatorCalculator` 读取前 120 根实时计算。分钟 K 走实时 Port `stock_minute_kline`（`MinuteKlinePort` → `PytdxMinuteKlineAdapter`，15 秒 Redis 缓存）。鉴权当前阶段保持公开。

- **采集复用**：`stock_info_service` 与 `panel_compose` 调 `collect.application.service.collect_manage_service.run_one` 触发业务采集（`/stocks/sync` → `run_one("stock_basic", "all")` 等）；

## 5. 关键技术点

### 5.1 18 个技术指标（请求时实时计算，不入库）

`IndicatorCalculator`（`market.domain.service.indicator_calculator`）读取前 120 根 K 线（`tech_daily`）→ 计算：

| 类别 | 指标 |
|---|---|
| 趋势 | MA（5/10/20/30/60）/ EMA（12/26）/ MACD / BOLL |
| 动量 | KDJ / RSI（6/12/24）/ CCI / WR / MTM / ROC |
| 成交量 | OBV / VOL_MA（5/10）/ VR |
| 波动 | ATR |

- **预热**：`GET /data-board/tech/kline/{symbol}` 与 `GET /klines/{symbol}` 默认 `with_indicators=true`；列表默认 `false`（仅 OHLCV）；
- **不落库**：所有指标在请求时算，避免日指标 18×`tech_daily` 的数据膨胀；
- **缓存**：4 个 tech 端点用 ETag（响应体 SHA1），命中率高的端点几乎零开销。

### 5.2 K 线复权

- `tech_daily` 是**未复权**行情（Tushare `daily` 原值）；
- `base_adj_factors` 提供**复权因子**（Tushare `adj_factor`，全量已回填 7.5M 行）；
- 查询时由 `IndicatorCalculator` 或专门计算层把 `adj_factor` 应用到 OHLCV 上（**按需计算**）；
- ⚠️ `tech_adj_factor` 表名在历史文档里叫 `tech_adj_factors` —— 实际为单数 `base_adj_factors`（2026-10-12 清理后统一）。

### 5.3 分钟 K 实时（`stock_minute_kline`）

- 数据源：通达信 pytdx（`PytdxClient` + `PytdxMinuteKlineAdapter`）；
- 缓存：Port 声明 `cache = CachePolicy(ttl_trading=15s, ...)`，`CacheDecorator` 写 `ds:cache:{port}:{hash}`，TTL 由 `market_session.ttl_for` 按交易时段动态决定（工作日 09:25–11:30 / 13:00–15:00 = 15 秒；午休 = 缓存到 13:00；非交易 = 缓存到下个工作日 09:25）；
- 单飞：`SET ds:lock:{port}:{hash} NX EX 5`，未抢到锁的最多等约 2 秒后重读缓存；
- 限流：`tdx` 限流组并发 = 1（`PytdxClient` 单连接加 `threading.Lock`）；
- 超时：单次取数 10 秒 → `SourceUnavailable` → 502；
- 业务侧对应 `GET /minute-klines/{symbol}`，由 `StockInfoService.get_minute_klines` → `DataGateway.fetch(MinuteKlinePort, QUERY)`；前端 15 秒轮询（`useRealtimePoll`）。

### 5.4 AI 归因统一入口（`/stocks/{symbol}/analysis`）

当前实现：组装（股票基础信息 + 形态摘要（`signal_detector`）+ K 线指标 + 所在池）→ 返回 JSON。
后续：接入 LangGraph 多 Agent 编排（异常检测 → 归因 → 报告），见 [`项目规划.md`](项目规划.md) §3。
