## 2. `key_manager.py` — RSA 密钥对

### 2.1 文件位置

`backend/src/infrastructure/security/key_manager.py`

### 2.2 职责

1. **启动时检查** `backend/.keys/jwt_private.pem` 是否存在：
   - 存在 → 加载
   - 不存在 → 生成新的 RSA 2048 位密钥对并写入（仅 600 权限）
2. **提供 `get_private_key()`** 给 `jwt_service.py` 签发
3. **提供 `get_public_key()`** 给 `jwt_service.py` 验证
4. **提供 `get_kid()`** 给 `jwt_service.py` 写入 JWT 头部 `kid` 字段

### 2.3 关键设计

| 项 | 选择 | Why |
|---|---|---|
| 算法 | RSA 2048 | 标准；非对称，私钥签公钥验 |
| 文件格式 | PKCS8 PEM | 行业标准；`cryptography` 库原生支持 |
| 存储位置 | `backend/.keys/jwt_private.pem` | 不在 src/ 内，方便 git ignore |
| 缓存 | 模块级单例 | 避免每次请求都读文件 |
| 密钥轮换 | 删除 `.keys/` 重启即换 | 简单 |

### 2.4 关键代码骨架（不需现在写，但设计已定）

```python
# 伪代码（实际写在 key_manager.py）

KEY_DIR = Path(__file__).parent.parent.parent.parent / ".keys"
PRIVATE_KEY_PATH = KEY_DIR / "jwt_private.pem"
PUBLIC_KEY_PATH  = KEY_DIR / "jwt_public.pem"

# 模块级缓存
_private_key: RSAPrivateKey | None = None
_public_key: RSAPublicKey | None = None
_kid: str | None = None

def _generate_keys() -> None:
    """生成新的 RSA 2048 密钥对"""
    KEY_DIR.mkdir(parents=True, exist_ok=True)
    private_key = rsa.generate_private_key(public_exponent=65537, key_size=2048, backend=default_backend())
    # 写 PEM，私钥设 600
    PRIVATE_KEY_PATH.write_bytes(private_key.private_bytes(
        encoding=serialization.Encoding.PEM,
        format=serialization.PrivateFormat.PKCS8,
        encryption_algorithm=serialization.NoEncryption(),
    ))
    PRIVATE_KEY_PATH.chmod(0o600)
    # 公钥
    public_key = private_key.public_key()
    PUBLIC_KEY_PATH.write_bytes(public_key.public_bytes(
        encoding=serialization.Encoding.PEM,
        format=serialization.PublicFormat.SubjectPublicKeyInfo,
    ))

def get_private_key() -> RSAPrivateKey:
    """获取私钥（启动时生成/加载）"""
    global _private_key, _kid
    if _private_key is None:
        if not PRIVATE_KEY_PATH.exists():
            _generate_keys()
        # load + 设置 kid（用文件 mtime）
        ...

def get_public_key() -> RSAPublicKey:
    if _public_key is None:
        get_private_key()  # 配套加载
        ...

def get_kid() -> str:
    """key id，用文件 mtime 字符串"""
    if _kid is None:
        get_private_key()
    return _kid

def _b64url_uint(n: int) -> str:
    """整数 → base64url 字符串"""
    nbytes = n.to_bytes((n.bit_length() + 7) // 8, byteorder="big")
    return base64.urlsafe_b64encode(nbytes).rstrip(b"=").decode("ascii")
```

## 3. `jwt_service.py` — JWT 签发/验证

### 3.1 文件位置

`backend/src/infrastructure/security/jwt_service.py`

### 3.2 职责

1. `create_access_token(user_id, username, email, roles, permissions)` → `(token, expires_at)`
2. `create_refresh_token(user_id)` → `(token, jti, expires_at)`
3. `decode_token(token, expected_type)` → claims dict（校验签名 + 过期 + iss + aud + type）

### 3.3 Token 设计

| 项 | access_token | refresh_token |
|---|---|---|
| 过期 | 15 分钟 | 7 天 |
| 用途 | API 鉴权（每次请求带） | 换新 access_token |
| claims | sub, email, username, **roles**, **permissions** | sub, jti |
| type claim | `"access"` | `"refresh"` |
| 算法 | RS256 | RS256 |
| 验证 | 验签 + 验过期 + 验 iss + aud | 验签 + 验过期 + 查 sys_refresh_tokens 表 |
| 存储 | 客户端 localStorage | 客户端 localStorage + 服务端 sys_refresh_tokens 表 |

### 3.4 claims 详细（access_token）

```json
{
  "sub": "123",                                    // 用户 ID（字符串）
  "iss": "attribution-auth",                       // 签发者
  "aud": "attribution-api",                        // 受众
  "iat": 1727865045,                               // 签发时间（秒）
  "nbf": 1727865045,                               // 生效时间
  "exp": 1727865945,                               // 过期（iat + 900s）
  "jti": "a3f5b8c1d2e4...",                        // JWT ID
  "username": "admin",
  "email": "admin@local",
  "roles": ["admin"],
  "permissions": ["stock:read", "stock:write", ...],  // 所有权限（含从角色聚合）
  "type": "access"
}
```

### 3.5 claims 详细（refresh_token）

```json
{
  "sub": "123",
  "iss": "attribution-auth",
  "iat": 1727865045,
  "exp": 1728479445,                               // iat + 7d
  "jti": "f9e8d7c6b5a4...",                        // 用于查 sys_refresh_tokens 表
  "type": "refresh"
}
```

> 注意：refresh_token **不**含 roles/permissions（够小，减少 JWT 体积）；换新 access_token 时由 `auth_app_service` 重新查 DB 聚合。

### 3.6 关键代码骨架

```python
# 伪代码
import jwt
from datetime import datetime, timedelta, timezone
import uuid
from infrastructure.security.key_manager import get_kid, get_private_key, get_public_key

ALGORITHM = "RS256"
ACCESS_TOKEN_EXPIRE = timedelta(minutes=15)
REFRESH_TOKEN_EXPIRE = timedelta(days=7)
ACCESS_TOKEN_AUDIENCE = "attribution-api"
ACCESS_TOKEN_ISSUER = "attribution-auth"

def _now(): return datetime.now(tz=timezone.utc)

def create_access_token(user_id, username, email, roles, permissions):
    now = _now()
    expires = now + ACCESS_TOKEN_EXPIRE
    payload = {
        "sub": str(user_id), "iss": ACCESS_TOKEN_ISSUER, "aud": ACCESS_TOKEN_AUDIENCE,
        "iat": int(now.timestamp()), "nbf": int(now.timestamp()),
        "exp": int(expires.timestamp()), "jti": uuid.uuid4().hex,
        "username": username, "email": email,
        "roles": roles, "permissions": permissions, "type": "access",
    }
    token = jwt.encode(payload, get_private_key(), algorithm=ALGORITHM, headers={"kid": get_kid()})
    return token, expires

def create_refresh_token(user_id):
    now = _now()
    expires = now + REFRESH_TOKEN_EXPIRE
    jti = uuid.uuid4().hex
    payload = {
        "sub": str(user_id), "iss": ACCESS_TOKEN_ISSUER,
        "iat": int(now.timestamp()), "exp": int(expires.timestamp()),
        "jti": jti, "type": "refresh",
    }
    token = jwt.encode(payload, get_private_key(), algorithm=ALGORITHM, headers={"kid": get_kid()})
    return token, jti, expires

def decode_token(token, expected_type="access"):
    payload = jwt.decode(
        token, get_public_key(), algorithms=[ALGORITHM],
        audience=ACCESS_TOKEN_AUDIENCE, issuer=ACCESS_TOKEN_ISSUER,
        options={"require": ["exp", "iat", "sub", "type"]},
    )
    if payload.get("type") != expected_type:
        raise jwt.InvalidTokenError(f"Token 类型错误: 期望 {expected_type}, 实际 {payload.get('type')}")
    return payload
```

### 3.7 关键设计

| 项 | 选型 | Why |
|---|---|---|
| 过期单位 | 秒（`int(now.timestamp())`） | JWT 规范 |
| 必填 claims | `exp, iat, sub, type` | 防止伪造或错用 |
| 验 audience | `attribution-api` | 防止"内部 token"被发到别的服务 |
| 验 issuer | `attribution-auth` | 同上 |
| 头部带 kid | `headers={"kid": get_kid()}` | 密钥轮换时区分新旧 key |
| jti | `uuid4().hex`（32 字符） | 全局唯一；用于 refresh_token 查表 |

## 4. `password.py` — bcrypt 密码

### 4.1 文件位置

`backend/src/infrastructure/security/password.py`

### 4.2 职责

1. `hash_password(plain) -> str` — bcrypt 哈希
2. `verify_password(plain, hashed) -> bool` — 验证

### 4.3 设计

| 项 | 值 | Why |
|---|---|---|
| 算法 | bcrypt | 自动加盐 + 可调成本 |
| cost | 12 | 250ms 一次哈希；平衡安全与体验 |
| 编码 | UTF-8 | 兼容中文密码（虽然不应该有）|
| 异常处理 | `verify` 失败时返回 `False`（不抛异常）| 登录接口不区分"用户不存在"和"密码错" |

### 4.4 关键代码骨架

```python
import bcrypt

def hash_password(plain: str) -> str:
    salt = bcrypt.gensalt(rounds=12)
    return bcrypt.hashpw(plain.encode("utf-8"), salt).decode("utf-8")

def verify_password(plain: str, hashed: str) -> bool:
    try:
        return bcrypt.checkpw(plain.encode("utf-8"), hashed.encode("utf-8"))
    except (ValueError, TypeError):
        return False
```

## 8. 测试要点

| 测试 | 用例 |
|---|---|
| `key_manager` | 首次启动生成密钥；二次启动加载同一密钥 |
| `jwt_service` | 签发后能解出 claims；过期 token 抛 `ExpiredSignatureError`；错签名抛 `InvalidSignatureError`；type 不匹配抛错 |
| `password` | 哈希后非明文；`verify(plain, hash) == True`；`verify(wrong, hash) == False`；错误 hash 不抛异常 |
| 端到端 | 注册→登录→拿 token→用 token 调 /me→返回正确 user_info；refresh token 用一次后变 rotation；reused detection 触发全撤销 |

## 9. 安全要点

| 要点 | 措施 |
|---|---|
| 私钥文件权限 | `chmod 600 jwt_private.pem`，`.gitignore` |
| 私钥文件位置 | `backend/.keys/`，**绝不提交** |
