总体内容
    backend\src\shared放公共的内容；backend\src\context，按模块区分上下文
    每个模块按照interface,domain,application,infrastructure区分接口层、领域层、业务层、基础设施层
    本地开发用backend\.env的环境变量；部署结合githubaction和k8s的yaml部署
interface层
    interface/dto存放入参和出参
    interface/route,存放对应的请求入口
    route层不注入dbsession等，只做前端请求的入口，接收参数传递给service层
    backend\src\shared\interface，存放了公共列表容器的page.py,router_compat.py聚合路由后续注册到main.py

domain层
    domain/entitys存放各个模块对应的领域模型，有vo,entity,repo
    domain/service存放各个模块跨领域的领域方法

application层
    application/bo,存放业务层用的BO
    application/port，存放调用底层需要的接口定义，不关心底层实现
    application/service，存放具体业务逻辑

infrastructure层
    infrastructure/connect，存放底层连接，比如数据库，reids等，
        shared模块存放了数据库redis，各个模块中只放自己独立需要的连接，比如collect模块的tushare的连接
    infrastructure/di,存放各个模块需要注入的依赖
        shared模块存放了dbsession的依赖
        各个模块di还额外将service都统一注入到di中让route或者其他模块注入调用
    infrastructure/persistence
        有model，定义orm模型，和repositories，定义持久化具体操作
