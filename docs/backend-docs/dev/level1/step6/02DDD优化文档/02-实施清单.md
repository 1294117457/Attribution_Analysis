#### BO 改造示例

**当前**（`domain/kline/bo.py`）：

```python
from pydantic import BaseModel

class KlineBO(BaseModel):
    id: int
    symbol: str
    trade_date: date
    close: float
```

**目标**（`application/bo/kline.py`）：

```python
from pydantic import BaseModel
from contexts.market.domain.entities.kline.entity import Kline

class KlineBO(BaseModel):
    id: int
    symbol: str
    trade_date: date
    close: float
    
    @classmethod
    def from_entity(cls, entity: Kline) -> "KlineBO":
        """从 Entity 构造 BO"""
        return cls(
            id=entity.id,
            symbol=entity.symbol,
            trade_date=entity.trade_date,
            close=entity.close,
        )
```

### 1.9 application/converter/（删除）

**删除文件**：

```
application/converter/
├── kline_converter.py          ❌ 删除
├── stock_info_converter.py     ❌ 删除
├── panel_converter.py          ❌ 删除
└── ...
```

**改造方式**：

将 `Converter.to_dto()` 方法 → `DTO.from_entity()` 静态方法。
将 `Converter.to_entity()` 方法 → `Entity.from_bo()` 静态方法。

**对比示例**：

| 改造前 | 改造后 |
|:--|:--|
| `KlineConverter.entity_to_dto(entity)` | `KlineResponseDTO.from_entity(entity)` |
| `KlineConverter.dto_to_entity(dto)` | `Kline.from_bo(dto)` |
| `KlineConverter.model_to_entity(model)` | `Kline.from_db(model)` 或 `model.to_entity()` |

### 1.10 infrastructure/persistence/models/

#### 每个 model 加 `from_entity` 和 `to_entity`

**当前**（`infrastructure/persistence/models/tech_kline.py`）：

```python
class KlineDB(Base):
    __tablename__ = "tech_kline_dailys"
    id = Column(Integer, primary_key=True)
    symbol = Column(String(10))
    ...
```

**目标**：

```python
from contexts.market.domain.entities.kline.entity import Kline

class KlineDB(Base):
    __tablename__ = "tech_kline_dailys"
    id = Column(Integer, primary_key=True)
    symbol = Column(String(10))
    ...
    
    @classmethod
    def from_entity(cls, entity: Kline) -> "KlineDB":
        """从 Entity 构造 ORM Model"""
        return cls(
            id=entity.id,
            symbol=entity.symbol,
            ...
        )
    
    def to_entity(self) -> Kline:
        """从 ORM Model 构造 Entity"""
        return Kline(
            id=self.id,
            symbol=self.symbol,
            ...
        )
```

## 7. 风险与回滚

### 7.1 风险

| 风险 | 影响 | 缓解 |
|:--|:--|:--|
| 大量 import 路径修改 | 可能漏改 | 用 IDE 的 find-and-replace + 全局 grep 验证 |
| 循环导入 | 应用层和 domain 层互引 | Entity 依赖 BO 时用 TYPE_CHECKING 延迟导入 |
| git 历史污染 | 看不到原子提交 | 按 context 分批提交，每批一个 commit |

### 7.2 回滚方案

每个 context 单独提交，回滚时 `git revert HEAD~1` 即可回退整个 context 的修改。
