# 05 实时查询改造：只描述缓存，取数走 Gateway

> 对应 README 流程 ④（实时查询）。阶段 P3。

## 1. 现状

`BaseRealtimeQuery` 子类（`stock_minute_kline`、`concept_minute`）同时承担了三件事：

1. **数据定义**：`facet` / `label` / `description` / `source` / `source_label`，与采集任务各写一套；
2. **取数**：`fetch()` 里自己 `get_registry().get(XxxFetcher)` + `to_thread`；
3. **查询语义**：参数规范化、缓存键、TTL、降级、调用方说明、试查参数。

`RealtimeQueryFramework` 负责缓存、单飞、同源并发（`SOURCE_CONCURRENCY`）、超时、降级、统计。

## 2. 改造后的分工

| 职责 | 改造前 | 改造后 |
| :-- | :-- | :-- |
| 数据元数据（facet / label / 数据源） | Query 类变量 | 取自 `dataset` 和其 Provider |
| 取数 | `Query.fetch()` | `DataGateway.fetch(dataset, ..., policy=QUERY)` |
| 同源并发 | framework `SOURCE_CONCURRENCY` | Throttle 中间件（03），与采集共享分组 |
| 页面参数 → Dataset 参数 | `normalize()` + `fetch()` 内部 | `normalize()` + `to_params()` |
| 结果 → 页面 JSON | `fetch()` 内部 | `to_view()` |
| 缓存键 / TTL / 降级 / 调用方 / 试查参数 | Query | Query（不变） |
| 缓存 / 单飞 / 超时 / 统计 | framework | framework（不变） |

实时查询是 Dataset 的一种"使用方式"：同一个 `ConceptMinute` 以后如果要入库，只需再写一个采集任务，不用重新定义数据。

## 3. 新的 BaseRealtimeQuery

```python
class BaseRealtimeQuery(ABC):
    name: ClassVar[str]                     # 保持现有名称：stock_minute_kline / concept_minute
    dataset: ClassVar[type[Dataset]]
    label: ClassVar[str] = ""               # 为空时取 dataset.label
    description: ClassVar[str] = ""         # 为空时取 dataset.description
    sort_order: ClassVar[int] = 100
    ttl_trading: ClassVar[int] = 15
    consumers: ClassVar[tuple[str, ...]] = ()
    sample_params: ClassVar[dict] = {}

    def normalize(self, params: dict) -> dict:      # 页面参数校验，非法抛 ValueError（不变）
        return dict(params)

    def to_params(self, params: dict) -> dict:      # 页面参数 → Dataset 参数；默认原样
        return params

    def to_view(self, items: list) -> Any:          # BO 列表 → 可 JSON 序列化的结果
        ...

    @abstractmethod
    def cache_key(self, params: dict) -> str: ...

    async def fallback(self, params: dict) -> Any:  # 不变
        return None
```

删除：`facet`、`sub_facet`、`source`、`source_label`、`fetch()`。`facet` / `sub_facet` 从 `dataset` 取；`source` / `source_label` 从该 Dataset 优先级最高的 Provider 的 `origin` 取，标签用统一映射：

```python
# datasource/core/provider.py
ORIGIN_LABELS = {"tushare": "Tushare", "ths": "同花顺", "tdx": "通达信", "eastmoney": "东方财富"}
```

## 4. 两个实时接口的改法

### stock_minute_kline

```python
class StockMinuteKlineQuery(BaseRealtimeQuery):
    name = "stock_minute_kline"
    dataset = MinuteKline
    label = "股票分 K"
    ...
    def normalize(self, params): ...                # 不变：symbol 6 位、interval、days / count 范围
    def to_params(self, p):
        count = p.get("count") or BARS_PER_DAY[p["interval"]] * p["days"]
        return {"symbol": p["symbol"], "interval": p["interval"], "count": count}
    def to_view(self, items): ...                   # 原 fetch() 里组装 items 的那段
```

`normalize` 里"北交所不支持"的校验可以保留（给页面更明确的提示）。即使去掉，`PytdxMinuteKline.supports()` 也会返回 False，Gateway 抛 `NotSupported`。

### concept_minute

```python
class ConceptMinuteQuery(BaseRealtimeQuery):
    name = "concept_minute"
    dataset = ConceptMinute
    label = "概念实时行情"
    ...
    def to_view(self, items):
        return items[0].model_dump() if items else None
    async def fallback(self, params): ...           # 不变：最近一条日 K 收盘
```

`ConceptMinute` Dataset 返回 `list[ConceptMinuteBO]`（统一为列表，单条时取第一个），保持 Dataset 返回值形状一致。

## 5. framework 的改动

只改 `_fetch`，其余（缓存、单飞、降级、统计）不动：

```python
async def _fetch(self, q: BaseRealtimeQuery, params: dict) -> Any:
    result = await asyncio.wait_for(
        get_data_gateway().fetch(q.dataset, q.to_params(params), policy=CallPolicy.QUERY),
        timeout=FETCH_TIMEOUT,
    )
    return q.to_view(result.items)
```

删除 `SOURCE_CONCURRENCY`、`DEFAULT_CONCURRENCY`、`_semaphores`。

`policy=QUERY` 表示限频时不等 60s，直接失败，进入现有的 `fallback` 降级（返回 `stale=true`）。这与现在的行为一致：现在实时接口本来也不等限频。

## 6. catalog 的改动

`CollectTaskRegistry.catalog()` 里组装实时接口 `TaskDef` 时：

- `facet` / `sub_facet` 取 `q.dataset`；
- `label` / `description` 取 `q.label or q.dataset.label`；
- `source` / `source_label` 取 `get_data_gateway()` 中该 Dataset 首选 Provider 的 `origin` / `ORIGIN_LABELS[origin]`。

前端拿到的字段不变。

## 7. 验收

- 股票列表展开行的分 K、详情抽屉的概念 Tab 正常；`/collect` 页"试查"正常。
- Redis 中 `rt:*` 缓存键和 `rt:stats:*` 统计格式不变。
- 停掉网络或模拟 adata 限流时，概念实时行情返回 `stale=true` 的降级数据。
