## 2. CollectContext

```python

@dataclass(frozen=True)
```

`di.py` 组装：

```python
@asynccontextmanager
async def _stock_info_scope():
    async with AsyncSessionLocal() as session:
        yield build_stock_info_service(session)
        await session.commit()

def build_collect_context() -> CollectContext:

    return CollectContext(
```

## 3. BaseCollectTask 绑定上下文

```python
class BaseCollectTask(ABC):
    name: ClassVar[str] = ""
    ...                                  # 元数据 / 执行配置不变

    def __init__(self) -> None:
        self._task_id: int = -1
        self._ctx: CollectContext | None = None

    def bind(self, ctx: CollectContext) -> None:
        self._ctx = ctx

    @property
    def ctx(self) -> CollectContext:
        if self._ctx is None:
            raise RuntimeError(f"{type(self).__name__} 未绑定 CollectContext（未经 setup_collect 注册）")
        return self._ctx
```

- 注册表 `setup` 时对每个任务调用 `bind(ctx)`，任务类定义不需要构造参数，声明式写法不变。
- 子类接口不变：`list_units` / `collect_one` / `existing_units` / `pending_units` / `estimate_total` / `run` / `summary_message` / `pre_execute` / `post_execute`。

## 4. CollectRunner（原 execute_task）

```python
# application/collect/runner.py
class CollectRunner:
    def __init__(self, tasks: CollectTaskStorePort, progress: CollectProgressPort) -> None: ...

    async def execute(self, task_id: int, handler: BaseCollectTask, params: dict) -> None:
        """流程与异常分支与现在 execute_task 完全一致：
        ① pre_execute  ② estimate_total → progress.set_total
        ③ run（on_unit_done：取消检查 → 累加 → progress.step）
        ④ 收尾：status = TaskOutcome(...).status → tasks.finish + progress.set_status
        Cancelled → cancelled；asyncio.CancelledError → cancelled 后继续上抛；其它异常 → failed
        finally：重置 cancel_check、post_execute、clear_cancel
        """
```

- 只依赖两个端口 + `application.port.data.context.cancel_check` + domain 的 `TaskOutcome`。
- 由 `di` 构造，注入 `CollectManageService`（替代现在直接 import 的 `execute_task`）。

## 5. 单元规划器与声明式任务

```python
# application/collect/planners.py
class UnitPlanner(Protocol):
    async def units(self, task: "DeclarativeCollectTask", params: dict) -> list[str]: ...

class TradeDatePlanner:
    async def units(self, task, params):
        return resolve_trade_dates(params)                 # 纯计算，不变

class SymbolPlanner:
    async def units(self, task, params):
        if params.get("symbol"):
            return [str(params["symbol"]).zfill(6)]
        symbols = await task.ctx.stocks.list_symbols("L")
        if params.get("only_missing") and task.incremental:
            existing = await task.ctx.raw_store.existing(task.port, None)
            symbols = [s for s in symbols if s not in existing]
        limit = params.get("limit")
        return symbols[: int(limit)] if limit else symbols

```

`ConceptPlanner` 现在没有任何任务使用（概念任务都是自定义 `run`），迁移时直接删除，不搬。

```python
# application/collect/declarative.py
class DeclarativeCollectTask(BaseCollectTask):
    port: ClassVar[type[DataPort]]
    planner: ClassVar[UnitPlanner]
    incremental: ClassVar[bool] = True      # 原 existing_column is not None
    unit_word: ClassVar[str] = "单元"
    empty_word: ClassVar[str] = "无数据"

    # __init_subclass__（元数据取自 Port）、build_params、summary_message 不变

    async def list_units(self, params):
        return await self.planner.units(self, params)

    async def existing_units(self, units, params):
        return await self.ctx.raw_store.existing(self.port, units) if self.incremental else set()

    async def collect_one(self, unit, params):
        result = await self.ctx.gateway.fetch(self.port, self.build_params(unit, params))
        if not result.items:
            return UnitResult(success=True, detail=unit, skipped=True)
        saved = await self.ctx.raw_store.save(self.port, result.items)
        return UnitResult(success=True, detail=unit, saved_count=saved)
```

规划器不再区分 `existing`：已有单元的查询统一走 `raw_store.existing`，规划器只负责"列出单元"。

## 8. 验收（C3）

- 手动提交任意任务：进度条、`current` 文案、完成状态、汇总文案与改前一致。
- 运行中取消：普通取消与强制取消都生效；Gateway 限流等待中也能及时响应取消（`cancel_check`）。
- 失败任务重跑、方案手动执行、定时方案触发（`trigger_type=schedule`）正常；`stop_on_fail` 行为不变。
- 服务重载时运行中任务记为 `cancelled`（"服务关闭中断"）。
- `application/service/collect_manage_service.py`、`application/collect/` grep 不到 `infrastructure.`。
