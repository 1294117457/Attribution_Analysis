# 05 — 后端·应用服务层

> 状态：方案，**未改代码**
> 范围：`application/service/auth_app_service.py`（**唯一**应用服务）
> 这是业务的"心脏"：注册/登录/刷新/登出 + 账户管理（启用禁用/重置密码/分配角色）

## 1. 位置与风格

```
backend/src/application/
├── port/                              # 现有（fetcher 协议 + 注册中心）
│   ├── collector_port.py
│   └── registry.py
├── service/
│   ├── ... (现有 8 个 service)

```

风格对齐：
- 构造 `__init__(self, session: AsyncSession)`（与 `StockAppService` 等一致）

## 2. 完整方法清单

| 方法 | 输入 | 输出 | 抛错 | 用途 |
|---|---|---|---|---|
| `register` | email, username, password, nickname? | `User` | `UserAlreadyExistsError` / `AuthError` | 邮箱注册 |
| `login` | email, password, user_agent, ip | `{access_token, refresh_token, expires_in, user_info}` | `InvalidCredentialsError` / `UserInactiveError` | 登录 |
| `refresh_token` | refresh_token | `{access_token, refresh_token, expires_in}` | `AuthError` / `TokenInvalidError` | 换新 token（含 rotation）|
| `logout` | user_id | None | — | 撤销该用户所有 refresh token |
| `parse_access_token` | access_token | claims dict | `AuthError` | 给 `deps_auth` 用 |
| `list_users` | page, page_size, keyword?, is_active? | `(list[User], total)` | — | 账户管理列表 |
| `update_user_status` | user_id, is_active | User | `UserNotFoundError` | 启用/禁用 |
| `reset_user_password` | user_id, new_password | None | `UserNotFoundError` / `AuthError` | 重置密码（强制重登）|
| `assign_role` | user_id, role_id | None | `UserNotFoundError` / `AuthError` | 分配角色 |
| `remove_role` | user_id, role_id | None | — | 移除角色 |
| `_get_user_permissions` | User | list[str] | — | 内部辅助：聚合所有角色的权限 |

## 3. 关键流程

### 3.1 register（注册）

```
输入: email, username, password, nickname?
  │
  ├─→ _validate_password(password)        # 长度 8-64
  ├─→ 校验 username 长度 3-32
  ├─→ user_repo.find_by_email(email)      # 唯一性
  │     └─ exists → raise UserAlreadyExistsError("email", email)
  ├─→ user_repo.find_by_username(username)
  │     └─ exists → raise UserAlreadyExistsError("username", username)
  │
  ├─→ 构造 User 实体
  │     password_hash = hash_password(plain)
  │     is_active = True, is_verified = False
  │
  ├─→ user_repo.create(user)              # 默认绑定 member 角色
  ├─→ session.commit()
  │
  └─→ return User
```

### 3.2 login（登录）

```
输入: email, password, user_agent, ip
  │
  ├─→ user_repo.find_by_email(email)
  │     └─ None → raise InvalidCredentialsError()  # 不区分"用户不存在"和"密码错"
  │
  ├─→ user.can_login() == False → raise UserInactiveError()
  │
  ├─→ verify_password(plain, user.password_hash) == False
  │     └─ raise InvalidCredentialsError()
  │
  ├─→ user.record_login(ip)               # 更新 last_login_at/ip + 发领域事件
  ├─→ user_repo.update(user)
  │
  ├─→ roles = [r.code for r in user.roles]
  ├─→ permissions = await _get_user_permissions(user)
  │
  ├─→ access_token, access_exp = create_access_token(user.id, username, email, roles, perms)
  ├─→ refresh_token, refresh_jti, refresh_exp = create_refresh_token(user.id)
  │
  ├─→ refresh_repo.save(user_id, jti, token, expires_at, user_agent, ip)
  │
  ├─→ session.commit()
  │
  └─→ return {
        access_token, refresh_token, token_type="Bearer", expires_in=900,
        user_info: { id, email, username, nickname, avatar_url, roles, permissions }
      }
```

### 3.3 refresh_token（刷新，**带 rotation**）

```
输入: refresh_token
  │
  ├─→ decode_token(token, expected_type="refresh")
  │     └─ ExpiredSignatureError → raise AuthError("Refresh token 已过期", "REFRESH_TOKEN_EXPIRED")
  │     └─ InvalidTokenError      → raise TokenInvalidError(str(e))
  │
  ├─→ jti = payload["jti"], user_id = int(payload["sub"])
  │
  ├─→ refresh_repo.find_by_jti(jti)
  │     └─ None → raise TokenInvalidError("Refresh token 不存在")
  │
  ├─→ token_record["revoked_at"] is not None
  │     └─ ⚠️ 已撤销的 token 又出现 → 可能的盗用
  │     └─→ refresh_repo.revoke_all_for_user(user_id)   # 全撤销
  │     └─→ session.commit()
  │     └─→ raise AuthError("检测到 token 盗用，已撤销该用户所有 token", "TOKEN_REUSE_DETECTED")
  │
  ├─→ refresh_repo.revoke(jti)            # 旧 token 撤销
  │
  ├─→ user_repo.find_by_id(user_id)
  │     └─ None or !can_login → raise InvalidCredentialsError()
  │
  ├─→ 重新聚合 roles + permissions
  ├─→ 签新 access_token + 新 refresh_token (新 jti)
  ├─→ refresh_repo.save(新 jti, 新 token)
  ├─→ session.commit()
  │
  └─→ return { access_token, refresh_token, token_type, expires_in }
```

### 3.4 logout（登出）

```
输入: user_id
  │
  ├─→ refresh_repo.revoke_all_for_user(user_id)
  ├─→ session.commit()
  │
  └─→ return None
```

### 3.5 update_user_status（启用/禁用）

```
输入: user_id, is_active
  │
  ├─→ user = user_repo.find_by_id(user_id)
  │     └─ None → raise UserNotFoundError(user_id)
  │
  ├─→ user.is_active = is_active
  ├─→ user = user_repo.update(user)
  ├─→ session.commit()
  │
  └─→ return User
```

> **注意**：禁用用户时是否要 revoke_all_for_user？**建议是**，否则禁用后 refresh_token 仍可换新 access_token。决策：**禁用时调用 `revoke_all_for_user`**。

### 3.6 reset_user_password（重置密码）

```
输入: user_id, new_password
  │
  ├─→ _validate_password(new_password)
  ├─→ user = user_repo.find_by_id(user_id)
  │     └─ None → raise UserNotFoundError(user_id)
  │
  ├─→ user.password_hash = hash_password(new_password)
  ├─→ user_repo.update(user)
  ├─→ refresh_repo.revoke_all_for_user(user_id)   # 强制重登
  ├─→ session.commit()
  │
  └─→ return None
```

### 3.7 assign_role / remove_role

```python
async def assign_role(self, user_id: int, role_id: int) -> None:
    user = await self.user_repo.find_by_id(user_id)
    if not user: raise UserNotFoundError(str(user_id))
    role = await self.role_repo.find_by_id(role_id)
    if not role: raise AuthError(f"角色 {role_id} 不存在", "ROLE_NOT_FOUND")
    # 检查是否已绑定（避免重复插入）
    existing = await self.session.execute(
        select(UserRoleDB).where(
            UserRoleDB.user_id == user_id, UserRoleDB.role_id == role_id,
        )
    )
    if existing.scalar_one_or_none():
        return  # 已绑定，幂等
    self.session.add(UserRoleDB(user_id=user_id, role_id=role_id))
    await self.session.commit()

async def remove_role(self, user_id: int, role_id: int) -> None:
    from sqlalchemy import delete
    await self.session.execute(
        delete(UserRoleDB).where(
            UserRoleDB.user_id == user_id, UserRoleDB.role_id == role_id,
        )
    )
    await self.session.commit()
```

### 3.8 _get_user_permissions（内部辅助）

```python
async def _get_user_permissions(self, user: User) -> list[str]:
    """聚合用户所有角色的权限 code"""
    if not user.roles:
        return []
    role_ids = [r.id for r in user.roles]
    stmt = (
        select(PermissionDB.code)
        .join(RolePermissionDB, RolePermissionDB.permission_id == PermissionDB.id)
        .where(RolePermissionDB.role_id.in_(role_ids))
        .distinct()
    )
    result = await self.session.execute(stmt)
    return [row[0] for row in result.all()]
```

> 之所以内部用 `PermissionDB` 和 `RolePermissionDB` 是因为这是查询 SQL 优化（一次查所有），不属于"领域逻辑"。**领域逻辑在 service 编排**。

### 3.9 parse_access_token（给 `deps_auth` 用）

## 4. 关键代码骨架（完整）

```python
# backend/src/application/service/auth_app_service.py
from __future__ import annotations

import logging
from typing import Optional

import jwt
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from domain.auth.entity import (
    User, UserAlreadyExistsError, UserNotFoundError, InvalidCredentialsError,
    UserInactiveError, TokenInvalidError, AuthError,
)
from domain.auth.repository import (
    UserRepository, RoleRepository, PermissionRepository, RefreshTokenRepository,
)
from infrastructure.persistence.repositories.auth_repository import (
    UserRepoImpl, RoleRepoImpl, PermissionRepoImpl, RefreshTokenRepoImpl,
)
from infrastructure.persistence.models.user_role import UserRoleDB
from infrastructure.persistence.models.user import PermissionDB
from infrastructure.security.jwt_service import (
    create_access_token, create_refresh_token, decode_token,
    ACCESS_TOKEN_EXPIRE,
)
from infrastructure.security.password import hash_password, verify_password

logger = logging.getLogger(__name__)


class AuthAppService:
    """认证应用服务（业务编排）"""

    def __init__(self, session: AsyncSession):
        self.session = session
        self.user_repo: UserRepository = UserRepoImpl(session)
        self.role_repo: RoleRepository = RoleRepoImpl(session)
        self.perm_repo: PermissionRepository = PermissionRepoImpl(session)
        self.refresh_repo: RefreshTokenRepository = RefreshTokenRepoImpl(session)

    # ════════════════════════════════════════════════════════════
    # 注册
    # ════════════════════════════════════════════════════════════

    async def register(
        self, email: str, username: str, password: str,
        nickname: Optional[str] = None,
    ) -> User:
        """注册（邮箱注册，不限学生邮箱）"""
        self._validate_password(password)
        if len(username) < 3 or len(username) > 32:
            raise AuthError("用户名长度需 3-32 字符")
        if await self.user_repo.find_by_email(email):
            raise UserAlreadyExistsError("email", email)
        if await self.user_repo.find_by_username(username):
            raise UserAlreadyExistsError("username", username)

        user = User(
            id=0, email=email, username=username,
            password_hash=hash_password(password),
            nickname=nickname or username,
            is_active=True, is_verified=False,
        )
        user = await self.user_repo.create(user)
        await self.session.commit()
        return user

    @staticmethod
    def _validate_password(password: str) -> None:
        if len(password) < 8:
            raise AuthError("密码至少 8 位")
        if len(password) > 64:
            raise AuthError("密码最多 64 位")

    # ════════════════════════════════════════════════════════════
    # 登录
    # ════════════════════════════════════════════════════════════

    async def login(
        self, email: str, password: str, user_agent: str = "", ip: str = "",
    ) -> dict:
        user = await self.user_repo.find_by_email(email)
        if not user:
            raise InvalidCredentialsError()
        if not user.can_login():
            raise UserInactiveError()
        if not verify_password(password, user.password_hash):
            raise InvalidCredentialsError()

        user.record_login(ip)
        await self.user_repo.update(user)

        roles = [r.code for r in user.roles]
        permissions = await self._get_user_permissions(user)

        access_token, access_exp = create_access_token(
            user.id, user.username, user.email, roles, permissions,
        )
        refresh_token, refresh_jti, refresh_exp = create_refresh_token(user.id)

        await self.refresh_repo.save(
            user.id, refresh_jti, refresh_token, refresh_exp, user_agent, ip,
        )
        await self.session.commit()

        return {
            "access_token": access_token,
            "refresh_token": refresh_token,
            "token_type": "Bearer",
            "expires_in": int(ACCESS_TOKEN_EXPIRE.total_seconds()),
            "user_info": {
                "id": user.id, "email": user.email, "username": user.username,
                "nickname": user.nickname, "avatar_url": user.avatar_url,
                "roles": roles, "permissions": permissions,
            },
        }

    # ════════════════════════════════════════════════════════════
    # 刷新（带 rotation）
    # ════════════════════════════════════════════════════════════

    async def refresh_token(self, refresh_token: str) -> dict:
        try:
            payload = decode_token(refresh_token, expected_type="refresh")
        except jwt.ExpiredSignatureError:
            raise AuthError("Refresh token 已过期", "REFRESH_TOKEN_EXPIRED")
        except jwt.InvalidTokenError as e:
            raise TokenInvalidError(str(e))

        jti = payload["jti"]
        user_id = int(payload["sub"])

        token_record = await self.refresh_repo.find_by_jti(jti)
        if not token_record:
            raise TokenInvalidError("Refresh token 不存在")
        if token_record["revoked_at"] is not None:
            # 复用检测
            await self.refresh_repo.revoke_all_for_user(user_id)
            await self.session.commit()
            raise AuthError("检测到 token 盗用，已撤销该用户所有 token", "TOKEN_REUSE_DETECTED")

        await self.refresh_repo.revoke(jti)

        user = await self.user_repo.find_by_id(user_id)
        if not user or not user.can_login():
            raise InvalidCredentialsError()

        roles = [r.code for r in user.roles]
        permissions = await self._get_user_permissions(user)

        new_access, _ = create_access_token(user.id, user.username, user.email, roles, permissions)
        new_refresh, new_jti, new_exp = create_refresh_token(user.id)

        await self.refresh_repo.save(user.id, new_jti, new_refresh, new_exp)
        await self.session.commit()

        return {
            "access_token": new_access,
            "refresh_token": new_refresh,
            "token_type": "Bearer",
            "expires_in": int(ACCESS_TOKEN_EXPIRE.total_seconds()),
        }

    # ════════════════════════════════════════════════════════════
    # 登出
    # ════════════════════════════════════════════════════════════

    async def logout(self, user_id: int) -> None:
        await self.refresh_repo.revoke_all_for_user(user_id)
        await self.session.commit()

    # ════════════════════════════════════════════════════════════
    # 解析 token（给 Depends）
    # ════════════════════════════════════════════════════════════

    async def parse_access_token(self, token: str) -> dict:
        try:
            return decode_token(token, expected_type="access")
        except jwt.ExpiredSignatureError:
            raise AuthError("Access token 已过期", "TOKEN_EXPIRED")
        except jwt.InvalidTokenError as e:
            raise TokenInvalidError(str(e))

    # ════════════════════════════════════════════════════════════
    # 账户管理
    # ════════════════════════════════════════════════════════════

    async def list_users(
        self, page: int = 1, page_size: int = 20,
        keyword: Optional[str] = None, is_active: Optional[bool] = None,
    ) -> tuple[list[User], int]:
        return await self.user_repo.list_users(page, page_size, keyword, is_active)

    async def update_user_status(self, user_id: int, is_active: bool) -> User:
        user = await self.user_repo.find_by_id(user_id)
        if not user:
            raise UserNotFoundError(str(user_id))
        user.is_active = is_active
        user = await self.user_repo.update(user)
        # 禁用时撤销所有 token（可选，推荐）
        if not is_active:
            await self.refresh_repo.revoke_all_for_user(user_id)
        await self.session.commit()
        return user

    async def reset_user_password(self, user_id: int, new_password: str) -> None:
        self._validate_password(new_password)
        user = await self.user_repo.find_by_id(user_id)
        if not user:
            raise UserNotFoundError(str(user_id))
        user.password_hash = hash_password(new_password)
        await self.user_repo.update(user)
        await self.refresh_repo.revoke_all_for_user(user_id)
        await self.session.commit()

    async def assign_role(self, user_id: int, role_id: int) -> None:
        user = await self.user_repo.find_by_id(user_id)
        if not user:
            raise UserNotFoundError(str(user_id))
        role = await self.role_repo.find_by_id(role_id)
        if not role:
            raise AuthError(f"角色 {role_id} 不存在", "ROLE_NOT_FOUND")
        existing = await self.session.execute(
            select(UserRoleDB).where(
                UserRoleDB.user_id == user_id, UserRoleDB.role_id == role_id,
            )
        )
        if existing.scalar_one_or_none():
            return
        self.session.add(UserRoleDB(user_id=user_id, role_id=role_id))
        await self.session.commit()

    async def remove_role(self, user_id: int, role_id: int) -> None:
        from sqlalchemy import delete
        await self.session.execute(
            delete(UserRoleDB).where(
                UserRoleDB.user_id == user_id, UserRoleDB.role_id == role_id,
            )
        )
        await self.session.commit()

    # ════════════════════════════════════════════════════════════
    # 内部辅助
    # ════════════════════════════════════════════════════════════

    async def _get_user_permissions(self, user: User) -> list[str]:
        if not user.roles:
            return []
        role_ids = [r.id for r in user.roles]
        stmt = (
            select(PermissionDB.code)
            .join(RolePermissionDB, RolePermissionDB.permission_id == PermissionDB.id)
            .where(RolePermissionDB.role_id.in_(role_ids))
            .distinct()
        )
        result = await self.session.execute(stmt)
        return [row[0] for row in result.all()]
```

## 5. 业务规则

| 规则 | 在哪实现 |
|---|---|
| 注册唯一性（email / username） | `register` 方法 |
| 密码强度（8-64） | `_validate_password` |
| 登录失败统一 `InvalidCredentialsError` | `login` 方法 |
| 禁用用户不能登录 | `User.can_login()` |
| 角色系统内置（admin/member/viewer）不可删 | UI 层提示；后端 `role_repo.delete` 检查 `is_system` |
| token rotation | `refresh_token` 方法 |
| 复用检测 | `refresh_token` 方法 |
| 重置密码强制重登 | `reset_user_password` |
| 禁用时撤销所有 token | `update_user_status(is_active=False)` |

## 6. 异常 → HTTP 状态码映射

| 异常 | 抛出处 | 状态码 | 响应 code |
|---|---|---|---|
| `UserNotFoundError` | update_user_status / reset_user_password / assign_role | 404 | 404 |
| `UserAlreadyExistsError` | register | 400 | 400 / USER_EXISTS |
| `InvalidCredentialsError` | login / refresh_token | 401 | 401 / INVALID_CREDENTIALS |
| `UserInactiveError` | login | 403 | 403 / USER_INACTIVE |
| `TokenInvalidError` | refresh_token / parse_access_token | 401 | 401 / TOKEN_INVALID |
| `AuthError("TOKEN_EXPIRED")` | refresh_token / parse_access_token | 401 | 401 / TOKEN_EXPIRED |
| `AuthError("TOKEN_REUSE_DETECTED")` | refresh_token | 401 | 401 / TOKEN_REUSE_DETECTED |
| `PermissionDeniedError` | （当前 service 不用，由 deps 抛）| 403 | 403 |
| `AuthError` 其他 | 校验/业务 | 400 | 400 |

> 当前 `main.py` 的 `register_exception_handlers` 已处理 `DomainError` → 400。如果需要按子类细分，需要在 handler 里做 isinstance 判断（**不推荐**，保持简单）。**前端根据 `data.code` 区分即可**。

## 7. 测试要点

| 测试 | 用例 |
|---|---|
| register | 成功；email 重复；username 重复；密码 7 位失败；密码 65 位失败 |
| login | 成功；user 不存在 → InvalidCredentials；密码错 → InvalidCredentials；用户禁用 → UserInactive |
| refresh_token | 成功（rotation）；过期 token → REFRESH_TOKEN_EXPIRED；伪造 token → TOKEN_INVALID；已撤销的 token 重用 → TOKEN_REUSE_DETECTED + 全撤销 |
| logout | 撤销该用户所有 refresh token |
| list_users | 关键字搜索；is_active 筛选；分页 |
| update_user_status | 启用；禁用（应同时撤销所有 token）|
| reset_user_password | 成功后该用户旧 token 失效 |
| assign_role | 重复分配幂等；分配不存在的 role_id 失败 |
| remove_role | 幂等（删不存在的也成功）|
