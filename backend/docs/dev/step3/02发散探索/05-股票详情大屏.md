# 05 — 股票详情大屏（全链路方案）

> 状态：方案，**未改代码**
> 路由：`/home/stock/:symbol/screen`（独立路由，从 `/home/stock-panel` 行点击 "大屏" 按钮跳转）
> 后端：**0 新接口**，复用 `GET /stocks/{symbol}/analysis` + `GET /moneyflows/{symbol}` + `GET /fin-daily-basics/{symbol}` + `GET /top10-holders/{symbol}` + `GET /dividends/{symbol}` + `GET /concepts/tab-by-symbol/{symbol}` + `GET /klines/{symbol}` + `GET /minute-klines/{symbol}`
> 前端：新建 1 个主页 + 3 个子组件
> 实时：分 K 部分 15s 轮询（复用 `useRealtimePoll`）

---

## 1. 业务需求

| 维度 | 说明 |
|---|---|
| 场景 | 进入股票"大屏"全屏视图，类似同花顺 F10 + 行情大屏合体 |
| 核心功能 | ① 头部：大字号代码 + 名称 + 现价 + 涨跌幅 + 关键指标条（PE/PB/总市值/换手/量比） ② 大屏 K 线（满屏宽） ③ 资金流向瀑布图（主力 / 大单 / 中单 / 小单） ④ 同行业横向对比（板块 vs 个股估值百分位） ⑤ 公告 / 新闻流（占位，本期用研报摘要接口） ⑥ 技术形态解读 ⑦ 所属概念 Tab（复用 `ConceptTab.vue`） |
| 路由 | `/home/stock/:symbol/screen` |
| 入口 | ① 详情抽屉新增 "大屏" 按钮 → 跳 `screen` 路由 ② `StockInfoList.vue` 行右键菜单（不改 row-click 行为） ③ 顶部面包屑：搜索 → 股票 → 大屏 |

### 4.3 `ScreenKlineChart.vue`（大屏 K 线）

```vue
<template>
  <div ref="chartRef" class="screen-kline"></div>

<script setup lang="ts">
import { ref, watch, onMounted, onUnmounted } from 'vue'
import * as echarts from 'echarts/core'
import { CandlestickChart, LineChart, BarChart } from 'echarts/charts'
import {
  GridComponent, TooltipComponent, LegendComponent,
  DataZoomComponent, AxisPointerComponent, TitleComponent, MarkLineComponent,
} from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
import { use } from 'echarts/core'

use([CandlestickChart, LineChart, BarChart, GridComponent, TooltipComponent, LegendComponent,
     DataZoomComponent, AxisPointerComponent, TitleComponent, MarkLineComponent, CanvasRenderer])

const props = defineProps<{ klines: any[]; symbol: string }>()
const chartRef = ref<HTMLDivElement>()
let chart: echarts.ECharts | null = null
let resizeObserver: ResizeObserver | null = null

function render() {
  if (!chartRef.value) return
  if (!chart) chart = echarts.init(chartRef.value)
  const dates = props.klines.map(k => k.date)
  const candleData = props.klines.map(k => [k.open, k.close, k.low, k.high])
  const ma5Data  = props.klines.map(k => k.ma5  ?? null)
  const ma10Data = props.klines.map(k => k.ma10 ?? null)
  const ma20Data = props.klines.map(k => k.ma20 ?? null)
  const ma60Data = props.klines.map(k => k.ma60 ?? null)
  const volData  = props.klines.map((k, i) => ({
    value: k.volume,
    itemStyle: { color: k.close >= k.open ? '#ef4444' : '#22c55e' },
  }))

  chart.setOption({
    title: { text: `${props.symbol} K线 + 17 指标`, left: 10, top: 5, textStyle: { color: '#f1f5f9', fontSize: 14 } },
    tooltip: { trigger: 'axis', axisPointer: { type: 'cross' } },
    legend: { data: ['K线', 'MA5', 'MA10', 'MA20', 'MA60'], top: 30, textStyle: { color: '#cbd5e1' } },
    grid: [
      { left: 60, right: 30, top: 70, height: '55%' },
      { left: 60, right: 30, top: '78%', height: '15%' },
    ],
    xAxis: [
      { type: 'category', data: dates, boundaryGap: false, axisLine: { lineStyle: { color: '#475569' } }, axisLabel: { color: '#94a3b8' } },
      { type: 'category', data: dates, scale: true, gridIndex: 1, boundaryGap: false, axisLine: { lineStyle: { color: '#475569' } }, axisLabel: { show: false } },
    ],
    yAxis: [
      { scale: true, axisLine: { lineStyle: { color: '#475569' } }, axisLabel: { color: '#94a3b8' }, splitLine: { lineStyle: { color: '#1e293b' } } },
      { scale: true, gridIndex: 1, splitNumber: 2, axisLine: { lineStyle: { color: '#475569' } }, axisLabel: { color: '#94a3b8' }, splitLine: { show: false } },
    ],
    dataZoom: [
      { type: 'inside', xAxisIndex: [0, 1], start: 70, end: 100 },
      { type: 'slider', xAxisIndex: [0, 1], top: '95%', height: 20, textStyle: { color: '#94a3b8' } },
    ],
    series: [
      { name: 'K线', type: 'candlestick', data: candleData },
      { name: 'MA5',  type: 'line', data: ma5Data,  smooth: true, lineStyle: { width: 1, color: '#fbbf24' }, showSymbol: false },
      { name: 'MA10', type: 'line', data: ma10Data, smooth: true, lineStyle: { width: 1, color: '#60a5fa' }, showSymbol: false },
      { name: 'MA20', type: 'line', data: ma20Data, smooth: true, lineStyle: { width: 1, color: '#a78bfa' }, showSymbol: false },
      { name: 'MA60', type: 'line', data: ma60Data, smooth: true, lineStyle: { width: 1, color: '#f472b6' }, showSymbol: false },
      { name: '成交量', type: 'bar', data: volData, xAxisIndex: 1, yAxisIndex: 1 },
    ],
  }, true)
}

onMounted(() => {

  resizeObserver = new ResizeObserver(() => chart?.resize())
  if (chartRef.value) resizeObserver.observe(chartRef.value)
})
watch(() => props.klines, render, { deep: true })
onUnmounted(() => {
  resizeObserver?.disconnect()
  chart?.dispose()
})
</script>
```

### 4.5 `ScreenPeerCompare.vue`（同业对比 — 估值百分位）

```vue
<template>
  <div class="sp-wrap">
    <h3>🏭 同行业对比（{{ industry }}）</h3>
    <div v-loading="loading" class="sp-content">
      <!-- 横向条形图：当前 PE / PB 在行业内的位置 -->
      <div ref="chartRef" class="sp-chart"></div>
      <div class="sp-legend">
        <span class="sp-legend__item">▼ 当前：PE {{ currentPe?.toFixed(1) }} / PB {{ currentPb?.toFixed(2) }}</span>
        <span class="sp-legend__item">中位数：PE {{ medianPe?.toFixed(1) }} / PB {{ medianPb?.toFixed(2) }}</span>
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, watch, onMounted, onUnmounted } from 'vue'
import * as echarts from 'echarts/core'
import { BarChart } from 'echarts/charts'
import { GridComponent, TooltipComponent } from 'echarts/components'
import { CanvasRenderer } from 'echarts/renderers'
import { use } from 'echarts/core'
import http, { unwrap } from '@/common/utils/http'

use([BarChart, GridComponent, TooltipComponent, CanvasRenderer])

const props = defineProps<{ symbol: string; currentBasics: any }>()
const industry = ref<string>('—')
const currentPe = ref<number | null>(null)
const currentPb = ref<number | null>(null)
const medianPe = ref<number | null>(null)
const medianPb = ref<number | null>(null)
const chartRef = ref<HTMLDivElement>()
let chart: echarts.ECharts | null = null
const loading = ref(false)

async function load() {
  loading.value = true
  try {
    // 1) 拿当前股的行业
    const cur = await http.get<any>(`/stocks/${props.symbol}`).then(unwrap)
    industry.value = cur.industry || '—'
    // 2) 拿行业全部股票的日频估值（最新一天）
    const all = await http.get<{ items: any[] }>(`/fin-daily-basics/`, {
      params: { symbol: '', limit: 5000 },  // 后端应支持按 industry 筛选；如不支持则前端过滤
    }).then(unwrap)
    // 3) 计算中位数
    const pes = all.items.map(i => i.pe_ttm).filter((x: any) => x != null && x > 0).sort((a: number, b: number) => a - b)
    const pbs = all.items.map(i => i.pb).filter((x: any) => x != null && x > 0).sort((a: number, b: number) => a - b)
    medianPe.value = pes.length ? pes[Math.floor(pes.length / 2)] : null
    medianPb.value = pbs.length ? pbs[Math.floor(pbs.length / 2)] : null
    currentPe.value = props.currentBasics?.pe_ttm
    currentPb.value = props.currentBasics?.pb

    if (chartRef.value) {
      if (!chart) chart = echarts.init(chartRef.value)
      chart.setOption({
        tooltip: { trigger: 'axis' },
```

## 7. 关键决策

| 问 | 答 |
|---|---|
| 为什么不复用 `KLineDrawerTab.vue`？ | 那个是抽屉内的小 K 线（~400px 高）；大屏要满屏宽（60%+ viewport） |
| 为什么要用深色背景？ | 大屏信息多 → 深色更聚焦、护眼（参考同花顺 / Wind） |
| 资金流向接口未实现怎么办？ | 大屏 `ScreenMoneyflowPanel.vue` 已带降级：catch → 显示占位文案 "⚠️ 资金流向接口未实现" |
| 同行业对比接口怎么支持？ | 如 `/fin-daily-basics/` 不支持 industry 筛选，前端拉全量后 in-memory filter（一次性 5000 行 ~ 50ms） |
| 大屏要不要支持 density？ | **不要**。大屏是固定布局（grid），density 锚点架构反而碍事。 |
