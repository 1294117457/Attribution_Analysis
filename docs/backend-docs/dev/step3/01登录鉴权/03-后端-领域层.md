## 2. `entity.py` — 实体 / 值对象 / 异常

### 2.1 继承关系

```
AggregateRoot (domain/base.py)
    └── User  ← 聚合根

ValueObject (domain/base.py, frozen=True)
    ├── Role
    └── Permission

Entity (domain/base.py)
    └── (无独立 User 之外的实体；其他都是值对象)

DomainError (domain/base.py)
    └── AuthError (基类)
        ├── UserNotFoundError
        ├── UserAlreadyExistsError
        ├── InvalidCredentialsError
        ├── UserInactiveError
        ├── TokenExpiredError
        ├── TokenInvalidError
        └── PermissionDeniedError
```

### 2.2 关键设计

| 决策 | Why |
|---|---|
| **User 是聚合根** | User 自己管理 roles（不另开 RoleAssignment 聚合，简化）|
| **Role / Permission 是值对象** | 只读 + 不可变，引用 ID/Code 即可 |
| **不用 SQLAlchemy/Pydantic** | 严格 DDD：领域层 0 框架依赖 |
| **所有 AuthError 继承 DomainError** | 复用现有 `register_exception_handlers` 统一响应格式 |
| **业务规则（`can_login` / `has_role` / `validate_password`）放领域对象方法** | DDD 行为归属对象 |

### 2.3 User 聚合根字段

| 字段 | 类型 | 来源 | 用途 |
|---|---|---|---|
| `id` | `int` | ORM 自增 | 实体标识 |
| `email` | `str` | 用户输入 | 登录账号 |
| `username` | `str` | 用户输入 | 显示名 |
| `password_hash` | `str` | bcrypt 哈希 | 凭证（不存明文）|
| `nickname` | `Optional[str]` | 用户输入 | 昵称 |
| `avatar_url` | `Optional[str]` | 用户上传 | 头像 |
| `is_active` | `bool` | 默认 `True` | 启用/禁用 |
| `is_verified` | `bool` | 默认 `False` | 邮箱是否验证（当前不强制）|
| `last_login_at` | `Optional[datetime]` | 登录时更新 | audit |
| `last_login_ip` | `Optional[str]` | 登录时更新 | audit |
| `created_at` | `Optional[datetime]` | DB 默认 | audit |
| `updated_at` | `Optional[datetime]` | DB 默认 | audit |
| `roles` | `list[Role]` | 加载时填充 | RBAC |

### 2.4 User 行为方法

| 方法 | 用途 |
|---|---|
| `validate_password(plain, hasher) -> bool` | 验证密码（注入 hasher 函数，避免领域层依赖 bcrypt）|
| `has_role(role_code) -> bool` | 是否拥有某角色 |
| `has_permission(perm_code) -> bool` | 占位（实际由 service 层聚合后判断）|
| `can_login() -> bool` | `is_active == True` 才允许登录 |
| `record_login(ip)` | 记录登录时间 + IP + 发 `UserLoggedIn` 事件 |

### 2.5 关键代码骨架

```python
# 伪代码
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional
from domain.base import AggregateRoot, ValueObject, DomainError, DomainEvent

# ── 值对象 ─────────────────────────────────────────────────────

@dataclass(frozen=True)
class Role(ValueObject):
    id: int
    code: str
    name: str
    def _get_values(self) -> tuple: return (self.code,)

@dataclass(frozen=True)
class Permission(ValueObject):
    id: int
    code: str
    resource: str
    action: str
    name: str
    def _get_values(self) -> tuple: return (self.code,)

# ── 聚合根 ─────────────────────────────────────────────────────

@dataclass
class User(AggregateRoot):
    id: int
    email: str
    username: str
    password_hash: str
    nickname: Optional[str] = None
    avatar_url: Optional[str] = None
    is_active: bool = True
    is_verified: bool = False
    last_login_at: Optional[datetime] = None
    last_login_ip: Optional[str] = None
    created_at: Optional[datetime] = None
    updated_at: Optional[datetime] = None
    roles: list[Role] = field(default_factory=list)

    def __post_init__(self):
        AggregateRoot.__init__(self)

    def validate_password(self, plain: str, hasher) -> bool:
        return hasher(plain, self.password_hash)

    def has_role(self, role_code: str) -> bool:
        return any(r.code == role_code for r in self.roles)

    def can_login(self) -> bool:
        return self.is_active

    def record_login(self, ip: Optional[str]) -> None:
        self.last_login_at = datetime.utcnow()
        self.last_login_ip = ip
        self.add_event(UserLoggedIn(user_id=self.id, ip=ip))

# ── 领域事件 ───────────────────────────────────────────────────

@dataclass
class UserLoggedIn(DomainEvent):
    user_id: int = 0
    ip: Optional[str] = None

# ── 领域异常（统一 code） ──────────────────────────────────────

class AuthError(DomainError):
    """认证错误基类"""
    def __init__(self, message: str, code: str = "AUTH_ERROR"):
        super().__init__(message, code)

class UserNotFoundError(AuthError):
    def __init__(self, identifier: str):
        super().__init__(f"用户不存在: {identifier}", "USER_NOT_FOUND")

class UserAlreadyExistsError(AuthError):
    def __init__(self, field: str, value: str):
        super().__init__(f"用户已存在 ({field}={value})", "USER_EXISTS")

class InvalidCredentialsError(AuthError):
    def __init__(self):
        super().__init__("邮箱或密码错误", "INVALID_CREDENTIALS")

class UserInactiveError(AuthError):
    def __init__(self):
        super().__init__("用户已被禁用，请联系管理员", "USER_INACTIVE")

class TokenExpiredError(AuthError):
    def __init__(self):
        super().__init__("Token 已过期", "TOKEN_EXPIRED")

class TokenInvalidError(AuthError):
    def __init__(self, reason: str = ""):
        super().__init__(f"Token 无效: {reason}" if reason else "Token 无效", "TOKEN_INVALID")

class PermissionDeniedError(AuthError):
    def __init__(self, required: str):
        super().__init__(f"权限不足: 需要 {required}", "PERMISSION_DENIED")
```

### 2.6 与现有 `domain/base.py` 的协作

复用现有基类：
- `AggregateRoot` — User 用
- `ValueObject` — Role / Permission 用
- `DomainError` — AuthError 继承 → 触发 `main.py` 已有的 `@app.exception_handler(DomainError)` → 统一 400 响应

**0 改动** `main.py` 即可。

## 3. `repository.py` — 仓储接口

### 3.1 4 个接口

```python
from abc import ABC, abstractmethod
from typing import Optional
from domain.auth.entity import User, Role, Permission


class UserRepository(ABC):
    @abstractmethod
    async def find_by_id(self, user_id: int) -> Optional[User]: ...
    @abstractmethod
    async def find_by_email(self, email: str) -> Optional[User]: ...
    @abstractmethod
    async def find_by_username(self, username: str) -> Optional[User]: ...
    @abstractmethod
    async def create(self, user: User) -> User: ...
    @abstractmethod
    async def update(self, user: User) -> User: ...
    @abstractmethod
    async def list_users(
        self, page: int = 1, page_size: int = 20,
        keyword: Optional[str] = None, is_active: Optional[bool] = None,
    ) -> tuple[list[User], int]: ...
    @abstractmethod
    async def delete(self, user_id: int) -> None: ...


class RoleRepository(ABC):
    @abstractmethod
    async def find_by_id(self, role_id: int) -> Optional[Role]: ...
    @abstractmethod
    async def find_by_code(self, code: str) -> Optional[Role]: ...
    @abstractmethod
    async def list_roles(self) -> list[Role]: ...
    @abstractmethod
    async def create(self, role: Role) -> Role: ...
    @abstractmethod
    async def update(self, role: Role) -> Role: ...
    @abstractmethod
    async def delete(self, role_id: int) -> None: ...


class PermissionRepository(ABC):
    @abstractmethod
    async def find_by_id(self, perm_id: int) -> Optional[Permission]: ...
    @abstractmethod
    async def list_permissions(self) -> list[Permission]: ...


class RefreshTokenRepository(ABC):
    @abstractmethod
    async def save(
        self, user_id: int, jti: str, token: str,
        expires_at, user_agent: str = "", ip: str = "",
    ) -> None: ...
    @abstractmethod
    async def find_by_jti(self, jti: str) -> Optional[dict]: ...
    @abstractmethod
    async def revoke(self, jti: str) -> None: ...
    @abstractmethod
    async def revoke_all_for_user(self, user_id: int) -> None: ...
```

### 3.2 设计要点

| 项 | 说明 |
|---|---|
| 全部 `async` | 与现有 `BaseSymboledDatedRepository` 一致；SQLAlchemy 2.0 async |
| 不返 ORM 模型 | 返聚合根（`User`）/值对象（`Role`/`Permission`）— 严格 DDD |
| `list_users` 返 `(list, total)` | 分页约定；与 `route/dto/response/panel.py` 风格一致 |
| `RefreshTokenRepository.find_by_jti` 返 `dict` | refresh_token 没有聚合根（轻量），用 dict 简化 |
