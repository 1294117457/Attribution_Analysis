# 当前数据采集实现 - 数据源 × 四面矩阵

> **目的**：盘点 `backend/src/infrastructure/adapter` 下已落地的数据源，标注每个 fetcher 采集什么、属于哪一面。
>
> **范围**：仅纳入已实现协议（Protocol）的 fetcher；尚未实现的表（资金面 6 张等）不在本文档范围。

---

## 一、数据源 × 协议 总览

```mermaid
flowchart LR
    subgraph Reg[数据源注册中心]
        R1[KlineFetcher]
        R2[MinuteKlineFetcher]
        R3[StockBasicFetcher]
        R4[DailyBasicFetcher]

    end

    TS[TushareFetcher<br/>pro.daily / pro.stock_basic<br/>pro.daily_basic] --> R1
    TS --> R3
```

> **关键**：`ConceptFetcher` 同时绑了两个实现（AkShare 作单例/工厂 + Adata 作工厂），调用方按能力选用。

## 二、各 fetcher 采集明细

### 1. TushareFetcher（tushare 源）

实现三个协议：`KlineFetcher` / `StockBasicFetcher` / `DailyBasicFetcher`

```mermaid
flowchart LR
    TS[TushareFetcher]
    TS -->|pro.daily| K[日 K 线 OHLCV]
    TS -->|pro.stock_basic| B[股票基本信息]
    TS -->|pro.daily_basic| DB[日频估值指标]

    K -.->|技术面| F1[tech_kline_daily]
    B -.->|基本面核心实体| F2[stock_info]
    DB -.->|基本面+资金面混合| F3[fin_daily_basic]
```

| 接口 | 采集字段 | 落表 | 所属面 |
| :-- | :-- | :-- | :-- |
| `pro.daily` | open/high/low/close/vol/amount/pct_chg | tech_kline_dailys | 技术面 |
| `pro.stock_basic` | ts_code / name / area / industry / market / list_date 等 | stock_infos | 基本面（核心实体）|
| `pro.daily_basic` | pe / pb / ps / dv_ratio / turnover_rate / total_mv / volume_ratio | fin_daily_basics | 基本面 + 资金面（混合）|

### 2. PytdxFetcher（通达信源）

实现协议：`MinuteKlineFetcher`

```mermaid
flowchart LR
    PT[PytdxFetcher<br/>get_security_bars]
    PT -->|1min / 5min / 15min<br/>30min / 60min| MK[分钟 K 线]

    MK -.->|技术面 - 辅助| F1[透传不落库]
```

| 接口 | 采集字段 | 落表 | 所属面 |
| :-- | :-- | :-- | :-- |
| `get_security_bars` | open/high/low/close/vol/amount + datetime | 不入库（前端实时拉）| 技术面 |

### 3. AkShareConceptFetcher（akshare THS 源）

实现协议：`ConceptFetcher`

```mermaid
flowchart LR
    AS[AkShareConceptFetcher]
    AS -->|stock_board_concept_name_ths| L[概念清单]
    AS -->|stock_board_concept_info_ths| S[概念行情快照]
    AS -->|stock_board_concept_index_ths| I[概念指数日 K]

    L -.->|市场全局| M1[mkt_sector_daily]
    S -.->|市场全局| M1
    I -.->|市场全局| M1
```

| 接口 | 采集字段 | 落表 | 所属面 |
| :-- | :-- | :-- | :-- |
| `stock_board_concept_name_ths` | name / code（375 个 THS 概念）| mkt_sector_dailys / concepts | 市场全局 |
| `stock_board_concept_info_ths` | 涨跌幅 / 涨跌家数 / 资金净流入 / 成交额 / 涨幅排名 | 行情快照 | 市场全局 |
| `stock_board_concept_index_ths` | 概念指数日 K（OHLCV）| 指数日 K | 市场全局 |

**不支持的能力**：`fetch_concept_stocks` / `fetch_concepts_by_stock` → 返回空 list（akshare THS 无 cons 端点）。

### 4. AdataConceptFetcher（adata THS 源）

实现协议：`ConceptFetcher`（仅作工厂，按需 create）

```mermaid
flowchart LR
    AD[AdataConceptFetcher]
    AD -->|stock.info.get_concept_ths| R[股票反查概念<br/>含入选理由]

    R -.->|市场全局 - 反向查询| M1[mkt_index_member]
```

| 接口 | 采集字段 | 落表 | 所属面 |
| :-- | :-- | :-- | :-- |
| `stock.info.get_concept_ths` | stock_code / concept_code / name / **reason** | mkt_index_members / concept_relations | 市场全局 |

**独家能力**：按股票代码反查所属概念 + 入选理由（akshare THS 没有）。

## 三、采集任务（scheduler/collect/）

```mermaid
flowchart TB
    subgraph CT[采集任务类]
        SK[StockBasicCollectTask]
        DK[DailyKlineCollectTask]
        DB[DailyBasicCollectTask]
        CC[ConceptCollectTask]
        OP[OperationDispatcher<br/>池 K 线派发]
    end

    SK -->|TushareFetcher| B[股票基本信息]
    DK -->|TushareFetcher| K[日 K 线]
    DB -->|TushareFetcher| V[日频估值]
    CC -->|AkShareFetcher| C[概念同步]
    OP -->|TushareFetcher 池| K
```

| 任务类 | 调用 fetcher | 单元维度 | 所属面 |
| :-- | :-- | :-- | :-- |
| `StockBasicCollectTask` | TushareFetcher | 整体 1 次 | 基本面（核心）|
| `DailyKlineCollectTask` | TushareFetcher | symbol × 并发 | 技术面 |
| `DailyBasicCollectTask` | TushareFetcher | trade_date 串行 | 基本面 |
| `ConceptCollectTask` | AkShareConceptFetcher | concept_name 串行 | 市场全局 |
| `OperationDispatcher` | TushareFetcher | symbol × 池 | 技术面 |

## 五、注册策略（registry 现状）

```mermaid
flowchart LR
    R[setup_default_registry]

    R -->|单例+工厂| T1[KlineFetcher = TushareFetcher]
    R -->|单例+工厂| T2[StockBasicFetcher = TushareFetcher]
    R -->|单例+工厂| T3[DailyBasicFetcher = TushareFetcher]
    R -->|单例+工厂| P[MinuteKlineFetcher = PytdxFetcher]
    R -->|单例+工厂| C1[ConceptFetcher = AkShareConceptFetcher]
    R -->|工厂 only| C2[ConceptFetcher = AdataConceptFetcher]
```

**当前实现的 4 个 fetcher 类、5 个协议绑定**，无 akshare 全市场行情 fetcher（只有概念）、无 tushare 财务/资金面 fetcher（接口未写）。
