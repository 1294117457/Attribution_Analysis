collect_service
    注入raw_data的session，log_service,持有Metadata
    1.派发采集任务
        log_service,创建日志获得log_id
        调用taskrunner.dispatch创建taskrunner后台任务携程,携带Metadata和logid
    2.配置好具体采集方法run_collect
        关于采集调用fetcher获取数据，
        数据处理，数据入库

taskrunner
    根据collect_service调用dispatch传入的Meta回掉collect_service的run_collect
    根据log_id更新redis中的日志
    注入log_service最终写库

log_service
    配置日志创建、更新、终态写库等方法

fetcher
    基于sdk实现的具体采集数据的方法
