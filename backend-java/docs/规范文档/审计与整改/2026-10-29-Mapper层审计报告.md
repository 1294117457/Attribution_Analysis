## 4. XML 手写分页（1 处）

```xml
<!-- ConceptMapper.xml:60 -->
LIMIT #{limit} OFFSET #{offset}
```

| 问题 | 后果 |
|---|---|
| 绕过分页插件 | 页码深时全表扫描后丢弃 |
| count 与 list 分离 | 总数与实际条数可能不一致 |
| 手工传 limit/offset | Service 侧要自己算 offset，易错 |

**整改**：改为 `Page<ConceptMemberPO>` + `selectPage`，或 XML 内去掉 LIMIT 由 Service 侧分页插件接管。

| `StockInfoMapper.selectSymbolsByMinTotalMv` | 单值 | — |

> ⚠️ 但该保护**散落在 Service 里**，新调用方可能忘记。因此建议**双保险**：
> XML 内统一加 `<choose><when test="...size() > 0">...<otherwise>NULL</otherwise></choose>`。
