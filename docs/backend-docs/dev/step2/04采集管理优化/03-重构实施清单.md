## 7. 风险与回退

| 风险 | 缓解 | 回退 |
| :- | :- | :- |
| Pipeline 配置写错（args_template 语法） | 单测覆盖 + 启动期校验 | 改回 BaseCollectTask 类 |
| 多步骤工作流执行慢 | step 间不强制串行；可加 `parallel: True` 标志 | 拆成单步 pipeline 跑 |
| 调度器触发风暴 | max_instances=1 + coalesce=True + 防重 | 关闭 scheduler |
| Redis 单实例锁失效（锁过期） | TTL 30s + watchdog 10s 心跳续期 | 关闭 scheduler |
| 老 8 个 ready task 类与新 pipeline 行为漂移 | P1 阶段做端到端对比测 | 关闭 `?use_pipeline=true` 开关 |
| 单元迭代器不支持新场景 | 扩展 `UnitResolver`，加 `unit_source="custom"` 走回调 | 写 BaseCollectTask 子类绕过 |
